# FLOW Editorial Finance Canvas：表达范式

本手册把 2026-10-18 A+C 概念板中的编辑部层级与财务画布表达拆成可复用模式。它约束信息表达，不限定每个项目必须使用同一导航或布局。

## 页面结构

### 编辑部页眉

- 页面标题用衬线字体表达主题；标题下用一行导语说明分析问题或结论边界。
- 期间、事实类别和筛选范围置于标题附近，但在视觉上次于标题与结论。
- 说明“数据是什么/不是什么”的标签应贴近数据，不藏在页面底部。

### 指标组

- 首屏优先显示 3–4 个当前任务必需的指标，单位与比较期紧跟数值。
- 数字使用等宽数字或 tabular numerals；同比/环比变化用文字、符号和语义色共同表达。
- 缺失/不可用值使用原因文字，不以 0 或空白卡片代替。

### 报告画布

- 主分析区使用大块低对比纸面，标题、图表和解释文字构成一个可独立阅读的区段。
- 图表与结论同屏；支持表、定义和来源可到达，不因装饰性卡片而被推至过远位置。
- 页面可采用非对称网格，但每个区块须说明在当前分析任务中的作用。

## 图表表达

- **趋势比较**：用于期间变化；标题点明指标，轴标明期间和单位，图例可直接区分数据系列。末端值标注只用于避免反复悬停读取。
- **构成/堆叠**：用于可加总的组成；保留总量、分类和单位。缺项保留缺失提示，不擅自补零。
- **瀑布/驱动桥**：用于从起点经变化项到终点的守恒关系；明确残差和方向。不存在的因子不得补造。
- **杜邦/因果拆解**：仅表达已定义的数学分解；把“分解”与“因果”区分开。
- **风险/热力**：必须有可追溯定义的分值和色阶；无经核验风险值时不生成装饰性矩阵。
- **同值表**：画布图表旁或紧邻位置提供同一数据的表格/文本形式，支持键盘和辅助技术。

## 色彩语义

- 海军蓝承载品牌框架和主要结构；纸白承载阅读面；古金用于有限强调，不映射成“好/坏”状态。
- 收入、利润、现金等图表系列按语义固定色值；多个公司/期间需要比较时先用线型、标签或明暗区分，避免只靠红绿。
- 正向、负向、警告、信息、不可用分别使用 `semantic` token，同时以文字或图标说明状态。
- 纸面和表格依赖细分隔线与轻层次；避免大面积高饱和渐变、厚阴影和装饰性噪声。

## 响应式与可访问性

- 桌面可用左右并置的主图与桥/支持区；平板收窄次要内容；手机先显示标题、结论和核心指标，再按分析顺序纵向阅读图表、支持表和来源。
- 图表、表格和页面本体不得造成横向溢出；确需宽数据表时由表区域承担横向滚动并保持首列/列标题可辨。
- 所有交互可键盘到达且有清晰焦点；文字、数据标签与背景符合对比度要求；状态不只用颜色表达。
- 支持 200% 缩放。动态图表提供静态数据表或摘要，不要求动画才能读取数据。

## 示例占位原则

`specimen.html` 只展示色块、文字阶层与布局占位，不包含虚构经营数值或状态。复制到其他项目时，应先替换内容语义，再按业务数据本身选择图表。
