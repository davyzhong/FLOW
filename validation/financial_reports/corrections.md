## 1. 压力测试 §2 十条"抽取错误"复核结论（2026-09-24）

结论：**十条全部为误报，抽取值本身全部正确**。分两类：

### 1a. 阿里巴巴 NCI 亏损行符号印刷差异（8 条）

菜鸟压力测试以"PDF 印刷值 vs YAML 值符号相反"判错。实际：港交所公告把
"歸屬於非控制性權益的虧損"印成正数（如"淨損失 9,083"），YAML 按会计符号
记负值（-9,083）。行名+绝对值同页成立，属强锚。

| 文件 | 行项 | YAML 值（本期/上期，百万元） | PDF 原文页 |
|---|---|---|---|
| alibaba_2020fy | 歸屬於非控制性權益損益 | -9,083 / -7,652 | FY2020 公告 p38 |
| alibaba_2021fy | 同上 | -7,294 / -9,083 | FY2021 公告 p35 |
| alibaba_2022fy | 同上 | -15,170 / -7,294 | FY2022 公告 p39 |
| alibaba_2024fy | 同上 | -8,677 / -7,210 | FY2024 公告 p33 |
| alibaba_2025fy | 同上 | -4,133 / -8,677 | FY2025 公告 p31 |
| alibaba_2026fy | 同上 | -1,465 / -4,133 | FY2026 公告 p31 |

处置：不改数据。答案集定位层新增 `strong-sign-flip-loss-row` 匹配模式
（仅强锚、仅当存在负数值、行名+绝对值同页），脚本 `scripts/build_answer_set_l1.py`
locate() 第三遍翻转适配；基准复验锚本来就按 abs(value) 校验，天然通过。

### 1b. 京东物流 2025 年报现金流量表图像页（2 条）

年报主表页为**图像层无文本**（pypdf 对 210 页全文检索"損益"零命中），
文本锚天然失效。已渲染 PNG 目视核对：

| 行项 | YAML 值（本期/上期，千元） | 证据 |
|---|---|---|
| 存放受限制現金 | (273,786) / (226,522) | evidence/jdl_fy2025_cf_p111.png（PDF 物理页 112 = 印刷页 111） |
| 已付利息 | (826,677) / (1,005,764) | evidence/jdl_fy2025_cf_p112.png（物理页 113 = 印刷页 112） |

处置：不改数据。新增 `visual-verified` 定位模式，登记于
`config/statements/l1_visual_verified.yaml`（含证据图 SHA-256），
构建/基准双端 fail-closed 校验（缺字段、证据缺失、SHA 不符均抛错）。

## 2. 复核中顺带发现的真错误（压力测试未捕获）

### 2a. alibaba_2023fy 上期列整列误抓（23 项）

原上期列 23 行全部是误抓的美元折算列/季度列小数字（如收入上期 30,729，
应为 FY2022 年度 853,062 百万元）。根因：该文件原 source_pdf 指向 FY2024
公告，FY2024 公告的上期列是 FY2023——数值本身没错但**定位锚错文件**，
且 FY2023 公告此前未归档。

处置（已完成）：
- 新归档 `p5_samples/alibaba_9988/BABA_FY2023_annual_results.pdf`
  （港交所公告，新浪镜像，SHA-256 `28256e2d…a9a7`，已登记 p5_samples README 与
  99_manifest）；
- 23 项上期值全部改录为 FY2023 公告载明的 FY2022 年度真实值（与已验证的
  alibaba_2022fy 本期列一致）；
- source_pdf 更正为 FY2023 公告。

### 2b. alibaba_2019fy NCI 上期 -406 误抓（1 项）

FY2020 公告 p38 美元折算列 406 被误抓为 FY2019 上期值。FY2018 真实值在
档案内不可验证（公开检索未获可靠来源）。

处置（已完成）：该值改为 `null` 并加注释（结构化缺失，不伪造）。答案集
总条目因此从 1795 变为 1794。
