# P5 首次抽取验证记录：顺丰控股 2026 年一季报

- 日期：2026-09-05
- 决策依据：D041-2（反向解析验证）、D042（样本选定）
- 样本：`docs/knowledge-base/02_research/original/p5_samples/sf_002352/SF_2026_Q1_report.pdf`（17 页，巨潮披露，SHA-256 前 16 位 `72a07309388abcdc`）
- 性质：P5 管道第一跑——目标是验证「PDF → 结构化报表行项目 → 勾稽/比对」链路可行，而非覆盖全部样本。

## 方法

1. **抽取**（`scripts/p5_extract_statements.py`）：pdfplumber 按表头特征行（项目/期末余额/本期发生额）自动定位报表起始、拼接续页，不硬编码页码；项目名去断行，数字解析处理千分位、`-`、空值；输出结构化 YAML。
2. **报表内勾稽**：资产负债恒等式、流动/非流动小计、归母+少数股东、利润链（营业利润→利润总额→净利润）、现金流小计/净额/期末现金推导，期末与上期两列全验，共 20 项。
3. **跨文档比对**（`scripts/p5_cross_validate_sf.py`）：三层——A 文档内（一季报正文「主要会计数据」vs 报表抽取值）、B 期初衔接（一季报期初 vs FY2025 年报 2025 年末合并数）、C 同期衔接（一季报上期列 2025Q1 vs FY2025 年报「分季度主要财务指标」Q1 列）。差异分级按规格 §10.2：一致/口径差异/解析误差/披露缺失。

## 结果

- **抽取**：合并资产负债表 73 行、合并利润表 45 行、合并现金流量表 45 行（共 163 行项目），产出 `docs/implementation/p5/sf_2026q1_statements.yaml`；
- **报表内勾稽：20/20 全部一致**（控制台逐项输出已核对）；
- **跨文档比对：12/12 全部一致**，比对表见 `docs/implementation/p5/sf_2026q1_diff_report.md`；
- 过程中发现并修复 1 处解析问题：一季报正文「归属于上市公司股东的所有者权益（千\n元）」存在跨行排版，数字被夹在断行中间，初版正则未取到（被正确标记为「披露缺失」而非误判一致）——说明差异分级机制能如实暴露解析缺陷；修复后复跑通过。

## 已知限制（诚实记录）

- 本次只覆盖顺丰一家、季度报告一份；年报（283 页）与中报的全量附注解析尚未做；
- 「归母净资产」一处初版解析失败说明 A 股 PDF 存在跨行排版风险，后续需在抽取层加断行合并的通用规则；
- 母公司报表：A 股季报仅披露合并口径（正文「母公司」字样均来自「归属于母公司」表述），母公司报表需在年报样本中验证；
- 腾讯/京东物流（PDF 排版与 IFRS 报表结构不同）尚未接入管道；
- 指标层（用抽取值计算指标库 40 通用指标并与披露指标比对）是下一步，本次只到报表行项目层。

## 可视化层（2026-09-05 增补，用户要求）

用户要求抽取出的「四表一注」具备良好的可视化效果（不止罗列表格），并包含图形化分析（饼图/柱状/趋势等）。已交付自包含 HTML 视图（无 CDN、内联 SVG 图表）：

- KPI 卡片带（收入/归母净利/经营现金流/总资产 + 同比）；
- 五季度趋势图（收入柱 + 归母净利线，2025Q1–2026Q1，数据分别来自年报分季度表与一季报，构建时现解析、不硬编码）；
- 利润形成瀑布图（收入→成本→各项损益→净利润），**构建期做瀑布链闭合校验，链断裂则构建失败、不出错图**；
- 资产构成与负债权益构成环形图（生成期做合计=总计闭合断言）；
- 现金流三活动本期 vs 上期分组柱状图；
- 六个分析指标卡（毛利率/归母净利率/资产负债率/ROE 单季口径/盈利现金含量/收入同比，均标注口径公式）；
- 四表全量抽取值可折叠表格；权益变动表与附注按「披露缺失」层级如实标注（A 股季报不披露）。

验证：Playwright 无头渲染零 JS 错误；截图肉眼复核中发现资产环形图初版误合计「合计行」（中心总额 6,750 亿 vs 正确 2,138 亿），已修复并加生成期闭合断言防回归。

## 可视化层第二轮（2026-09-06 增补，用户要求）

用户要求继续增加杜邦树、结构堆叠、同业对比三种分析视图。生成器新增三板块（仍全部构建期现解析、闭合断言、无 CDN）：

- **杜邦分析树**（板块⑤）：ROE（单季未年化，期末口径）2.52% = 归母净利率 3.41% × 总资产周转率 0.35 次 × 权益乘数 2.13，叶节点挂四个绝对值（归母净利 25.26 亿 / 收入 741.42 亿 / 资产总计 2,137.97 亿 / 归母净资产 1,004.10 亿）；下钻第二层：归母净利率 = 毛利率 13.7% − 期间费用率 9.1% − 税金·其他损益·所得税等 1.2pp。三因子乘积=ROE、下钻三项=净利率均在生成期断言闭合；页面注明与一季报正文「加权平均净资产收益率」口径不同、不可直接互比。
- **结构堆叠**（板块⑥）：营业总成本构成（本期 vs 上期，六分项加总 = 营业总成本 708.90/669.23 亿，两列闭合断言；利息费用/利息收入为财务费用其中项不重复计入）；资产构成（期末 vs 期初，与环形图同一 Top 项口径，两列分别闭合到资产总计 2,137.97/2,164.69 亿）。
- **同业对比**（板块⑦）：顺丰 vs 京东物流分组柱状 + 指标表。京东物流数字构建期现解析自 `jd_logistics_2618/JDL_2026_Q1_financial_info.pdf`（p3 摘要表、p7 Non-IFRS 归母）与 `JDL_FY2025_annual_results_announcement.pdf`（p2 全年摘要，p1 为 Q4 单季表勿用；p20 年度利润归属、p25 Non-IFRS 归母）：2026Q1 收入 605.81 亿 / 归母 8.80 亿 / 毛利率 8.0%，FY2025 收入 2,171.47 亿 / 归母 66.47 亿 / Non-IFRS 归母 73.84 亿。顺丰 FY2025 全年数 = 年报分季度加总，并与年报「主要会计数据」表数字闭合校验。口径标注：京东物流为 IFRS 港股未经审计口径（§10.2「口径差异」）；顺丰无 Non-IFRS 披露 → 如实标「披露缺失」。
