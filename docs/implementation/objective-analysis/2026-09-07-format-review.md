## 2. 需用户拍板的格式决策点

1. **量纲总策略**：现为"图表自动选量纲（亿元为主）+ 正文表格统一『亿』"，
   两处量纲独立、各自内洽。备选：全文强制统一『亿』；或全文跟随披露原单位。
2. **封面单位行表述**：现声明"单位：人民币千元"（源数据单位），与正文"亿"并存。
   备选："源数据单位：人民币千元 · 展示单位：亿元人民币"。
3. **每页页脚 + 页码**：现页脚仅末页出现、无页码（每页固定页脚经实测会遮切
   页底内容，已放弃）。每页页码需改用 Chromium DevTools 协议
   headerTemplate/footerTemplate，属小增量开发——是否立项。
4. **分页策略**：现按章节强制分页（章节起页清晰，但页尾留白 30–50%）；
   备选：连排（紧凑，章节可能从页中开始）。
5. **引擎表数值取整**：现展示引擎原始计算值（如 0.1099217361…）；
   备选：按指标类型取整（比率 4 位小数）。
6. **涨跌配色**：现为红涨绿跌（中国惯例）；备选：绿涨红跌（国际惯例）。
7. **资产结构环形图口径**：现百分比分母为"选列主要资产项合计"（标题已注明）；
   备选：分母改总资产（需在图内自定义百分比计算）。
8. **缺表章节呈现**：主体缺资产负债表时（腾讯公告），"资产、资本与偿债"节
   现保留并显式"—"；备选：整节省略并在数据边界说明。
