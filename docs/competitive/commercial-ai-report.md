# 商业 AI 财报分析产品

> 调研时点：2026-09-15。覆盖面向投资 / 投行 / 审计的 AI 财分 SaaS 头部产品。

## 一、市场观察

2023-2026 是"AI + 财分"商业产品的爆发期。商业模式：

- **订阅制**：按用户 / 按企业 / 按查询量
- **数据 + AI 打包**：自带数据 + AI 解读，区别于纯数据终端（Wind/iFinD）
- **LLM 后端**：多数产品包装 OpenAI / Anthropic / 自研金融 LLM

主要玩家画像：

| 公司 | 成立 | 估值 / ARR | 定位 |
| --- | --- | --- | --- |
| AlphaSense | 2011 | ~$10B ARR | 投行研究 + 企业战略情报 |
| Hebbia | 2020 | ~$700M 估值 | 金融文档 LLM |
| Tagnos / 启元 | 2023 | — | 中国版 AlphaSense |
| 通联数据 (DataYes) | 2014 | — | 中国本土金融数据 + AI |
| 熵简科技 | 2018 | — | 国内另类数据 / 投研 AI |
| ChatInsight | 2024 | — | 国内金融问答 LLM |

## 二、AlphaSense

- **核心能力**：聚合「投行研报 + 公司财报 + 行业新闻 + 监管文件」，用 AI 帮分析师快速找信息 + 跨文档交叉验证
- **AI 模型**：自研金融领域 LLM（基于公开模型微调），主力卖点是「企业财报 / 10-K / 10-Q 的全文搜索 + 摘要 + 跨文档追问」
- **数据来源**：覆盖 35,000+ 家公司、150+ 万份文档；订阅制带来数据护城河
- **用户**：投行（Goldman / Morgan Stanley）、买方（BlackRock / Fidelity）、企业战略（Cisco / Nike）
- **对 FLOW 启发**：
  - ① "跨文档追问" 是核心差异化：用户问 "Apple 的服务收入在最近 3 年发生了什么变化？"，AI 在多份 10-K / 10-Q / 电话会议纪要里找答案
  - ② FLOW 可以加一个"指标 × 多公司 × 多期间"的问答能力，比单公司摘要更有价值
  - ③ 数据护城河 = 自带数据集；FLOW 的事实库是稀缺资产，要继续深耕

## 三、Hebbia

- **核心能力**：长文档 LLM，单文档 100k tokens、跨文档问答。亮点：表格识别 / Excel 上传 / 多文档对比
- **AI 模型**：基于 GPT-4 + Claude 的 wrapper，加上自研结构化输出层
- **用户**：投行、对冲基金、PE
- **对 FLOW 启发**：
  - ① 表格识别：能把扫描版 PDF 财报的表格数字化。FLOW 已经做了 PDF 文本抽取（`p5_query_facts.py`），下一步可加"基于事实库反向生成 Excel 报表"
  - ② 多文档对比：用户上传多份 10-K，AI 输出并排差异。FLOW 的"跨公司对标"是同一思路

## 四、Tagnos / 启元

- **定位**：AlphaSense 的中国版。聚焦 A 股 / 港股 / 美股中概
- **核心能力**：聚合中文研报 + 公告 + 财报 + 新闻，AI 问答
- **商业模式**：按用户订阅，10万-50万元/年/人
- **对 FLOW 启发**：
  - ① 中国本土玩家的定价对比 FLOW 的"内部平台"——FLOW 是给企业内部分析师用，对标 SaaS 时要看"分析师人均成本"
  - ② 中文研报 / 公告是 FLOW 当前没覆盖的，可作未来"非结构化数据"路线

## 五、通联数据 (DataYes)

- **定位**：中国本土金融数据 + AI 老牌玩家
- **核心能力**：基础金融数据（股票 / 基金 / 债券 / 衍生品）+ 另类数据（电商 / 物流 / 出行 / 卫星）+ 投研 AI 助手
- **独特卖点**：另类数据覆盖国内电商销量 / 物流时效 / 出行热度，可作为前瞻指标
- **对 FLOW 启发**：
  - ① "另类数据" 是 FLOW 当前完全没有的方向——FLOW 只用了公开财报数据。如果未来 FLOW 想做"经营领先指标"，需要接入另类数据
  - ② 数据护城河 = 难以复制的来源。FLOW 反向解析财报的标准化做法有一定壁垒，但还不到通联的级别

## 六、熵简科技

- **定位**：国内另类数据 + AI 投研
- **核心能力**：电商销量、APP 下载量、招聘广告、专利申请、政策文本等
- **商业模式**：数据 + AI 打包，按报告 / 按 API 计费
- **对 FLOW 启发**：
  - ① 与通联类似，"另类数据" 是 FLOW 当前的空白

## 八、对 FLOW 的核心启发

1. **AI 问答是下一波必争之地**：所有头部产品都把 LLM 作为主要入口。FLOW 当前没有 Q&A，应该考虑：
   - 第一步：基于 fact_store 的检索增强（RAG），让用户问"顺丰的净利率为什么下降"
   - 第二步：跨公司跨期间对比，如"对比 5 家物流公司的运营效率"
   - 第三步：基于预测模型的"如果...那么..."模拟
2. **数据是护城河**：头部玩家的差异主要是「数据广度 × 数据深度 × 数据更新及时性」。FLOW 的 14 份财报 + 670 事实 + 167 科目是小型护城河，但还不到行业级。如果要做行业领先，需要 5–10 倍数据扩张。
3. **私有化 / 数据合规是中国市场核心需求**：Tagnos / 通联都在做私有化。FLOW 已经选了「本地部署 + 开源 + 企业内用」路线，符合中国大客户需求。
4. **PDF 抽取是基础能力，但 OCR 仍是壁垒**：AlphaSense / Hebbia 卖得贵很大原因是 OCR 准确率。FLOW 的 P5 抽取对中文 PDF 的识别已经走通，下一步可加「基于事实库的智能问答」叠加 OCR。
