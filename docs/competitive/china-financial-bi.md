# 中国本土财务数据与 BI

> 调研时点：2026-09-15。重点对象：Wind / 同花顺 iFinD / 东方财富 Choice / 通联数据 / 帆软 FineBI / 大智慧 / 通达信 / 雪球 / 聚宽 / 米筐。

## 一、市场总览（数据来自山东财经大学深圳研究院 2025 报告）

| 指标 | 数值 |
| --- | --- |
| 国内 B 端财经数据市场规模 | ~187.3 亿元 |
| CR3 市占率（Wind + Choice + iFinD） | ~68.5% |
| Wind 在持牌金融机构渗透率 | >85% |
| Choice 定价区间 | Wind 的 1/5 ~ 1/8 |

三层梯队：
- **第一梯队**：Wind / Choice / iFinD（综合型，全国性）
- **第二梯队**：大智慧 / 通达信 / 通联数据（垂直细分）
- **第三梯队**：巨灵财经 / 各地区域性服务商

## 二、Wind（万得）— 行业老大哥

- **定位**：综合金融数据终端，机构客户的「标配」
- **核心能力**：
  - 完整历史数据库：股票 / 债券 / 衍生品 / 基金 / 外汇 / 商品 / 指数
  - 全品类指标：1 万+ 财务 / 估值 / 风险 / 量化指标
  - Excel 插件：把数据拉到 Excel，分析师日常
  - **行业研究模板**：杜邦 / VAS / 估值 / 同业对标都是现成模板
  - **Wind 智能投研 / Wind GPT（2024+）**：LLM 接入财报解读 / 研报搜索 / 自动问答
- **定价**：单账号年费  数万到数十万元
- **商业模式**：纯订阅制 + 高门槛（最低 6-8 万/年/账号）
- **对 FLOW 启发**：
  - ① Wind GPT 是直接竞品（FLOW 应考虑 Q&A 方向）
  - ② 行业研究模板是 Wind 的差异化——FLOW 应该建自己的「行业指标体系模板」
  - ③ 但 Wind 的核心壁垒是「数据颗粒度 + 数据更新及时性 + 客户关系」，FLOW 短期内无法追上

## 三、同花顺 iFinD

- **定位**：Wind 的"性价比版"，C 端流量带动 B 端（证券 APP 月活 3549 万）
- **核心能力**：
  - iFinD 终端：与 Wind 类似的全功能，但定价更亲民
  - **数据接口 SDK**：C# / C++ / Java / MATLAB / R / VBA / Python（金融全语言覆盖）
  - **iFinD 移动端**：分析师随时查
  - 港股 / 美股 / A 股 / 期货 / 基金全市场
  - 行情报价实时性：A股 1 分钟级延迟，港股/美股 15 分钟延迟（Wind 类似）
- **定价**：高校版数千元/年/账号，专业版数万元/年/账号
- **商业模式**：双线（C 端 APP + B 端终端）
- **对 FLOW 启发**：
  - ① 数据接口标准化（API + SDK）值得借鉴；FLOW 当前是「数据进 PostgreSQL + OpenAPI 暴露」，相对成熟
  - ② C 端 + B 端双线是 iFinD 的护城河，FLOW 是"企业内部分析师"——方向不同
  - ③ 港股 + 美股 + A 股的全市场覆盖，FLOW 当前只有港股（顺丰 / 京东物流 / 腾讯 / 阿里）+ 美股样本（阿里巴巴美股部分）。FLOW 应考虑补 A 股样本公司

## 四、东方财富 Choice

- **定位**：东方财富旗下，主打「性价比 + 中小机构」，东方财富网 C 端流量转化
- **核心能力**：
  - Choice 终端：功能类似 iFinD
  - **核心数据免费**：行情 + 财报数据 + 公告免费（C 端引流）
  - **股吧 / 社区**：用户讨论产生 UGC（与其他玩家差异化）
  - 量化研究 + 因子库
- **定价**：批量采购 1/5 ~ 1/8 Wind
- **商业模式**：C 端免费引流 → B 端批量采购
- **对 FLOW 启发**：
  - ① 数据免费 + 增值付费 是 Choice 的路径。FLOW 不走这条（FLOW 是企业内部分析）
  - ② "股吧 / 社区" 提供另类数据（非结构化文本），可作 FLOW 未来数据源扩展方向
  - ③ 中小机构 / 私募 是 Choice 的核心客户，FLOW 也应该考虑「中小机构 SaaS 版」路线

## 五、帆软 FineBI

- **定位**：中国 BI 老大哥（市占率国内第一），自研 BI + 报表工具 + 数据集成
- **核心能力**：
  - 拖拽式 dashboard + 50+ 可视化
  - 自助式分析（业务方友好）
  - **业务包模板**：财务分析 / 经营分析 / 杜邦分析 等开箱即用模板
  - **国产化适配**：信创 / 麒麟 OS / 国产数据库
  - FineReport（报表工具）+ FineBI（自助 BI）+ 简道云（零代码）
- **商业模式**：企业级 SaaS / 私有化 / 国产化订阅
- **对 FLOW 启发**：
  - ① 「业务包模板」是 FineBI 的核心差异化。FLOW 已经做了「物流指标字典 + 杜邦拆解」方向，但还没做「开箱即用 dashboard 模板」。可以做：
    - 物流行业财务分析 dashboard 模板
    - 经营快照自动生成模板
    - 同业对标分析模板
  - ② 国产化适配 FineBI 是最强的。FLOW 私有部署要保持与信创兼容
  - ③ 但 FineBI 是"通用 BI + 模板"，FLOW 是"专门针对财报分析"——FLOW 可以做"专门化产品"，比 FineBI 更深

## 六、通联数据 (DataYes)

- **定位**：金融数据 + 另类数据 + 投研 AI
- **核心能力**：
  - 基础金融数据（股票 / 基金 / 债券）
  - **另类数据**：电商销量、APP 下载、招聘广告、专利
  - **AI 投研助手**：萝卜投研（自然语言问数）
  - 量化因子库
- **商业模式**：数据 API + 投研 AI 订阅
- **对 FLOW 启发**：
  - ① 另类数据是通联的差异化。FLOW 当前只有公开财报 → 应该考虑接入另类数据作为"前瞻指标"
  - ② "萝卜投研"自然语言问数，是 FLOW 未来必须有的能力

## 七、聚宽 (JoinQuant) / 米筐 (RiceQuant) — 量化平台

- **定位**：量化研究 + 回测 + 实盘
- **核心能力**：
  - Python 策略开发
  - 历史数据回测
  - 因子库 / 研报 / 社区
- **商业模式**：免费 / 收费策略订阅
- **对 FLOW 启发**：
  - ① 与 FLOW 不重合（FLOW 不做交易）
  - ② 但聚宽的「研报 / 因子库」是数据资产，可以借鉴

## 八、其他

- **大智慧 / 通达信**：行情 + 基础财务数据，老牌玩家，主要面向散户
- **雪球**：社区 + 行情 + 投资策略，C 端流量巨大
- **恒生电子 / 金证股份**：金融 IT 厂商，做 SaaS 化金融数据解决方案
- **理杏仁 (LiXing) / 乌龟量化**：财务数据筛选与可视化工具

## 九、对 FLOW 的核心启发

1. **市场分层清晰，FLOW 应明确定位**：
   - 第一梯队（Wind / iFinD / Choice）：通用金融终端市场，FLOW 进不去
   - 第二梯队（FineBI / 通联 / 大智慧）：垂直细分，FLOW 可以切入
   - **第三梯队**：FLOW 应专注 — "面向企业内部分析师的 AI 财报分析平台"
2. **定价差异化**：Wind 8 万/年/账号 vs Choice 1-2 万/年/账号。FLOW 如果做企业版，可以走"项目制 + 一次性"或"SaaS 订阅 + 数据更新"。避免与 Wind / Choice 在通用市场血战。
3. **数据护城河 = 数据广度 + 深度 + 时效 + 关联**。FLOW 当前 14 份财报 + 670 事实 + 167 科目 → 应优先扩"广度"（样本公司 5 → 50）和"深度"（每家覆盖 5 年 → 10 年财报）。
4. **AI 问数（Q&A）是 FLOW 必投**。所有头部产品都在做。
5. **业务包模板 + 行业模板**是 FineBI 差异化经验。FLOW 应该做"行业 dashboard 模板市场"。
6. **国产化 / 信创适配**是 B 端采购的硬指标。FLOW 应在部署文档明确支持。
