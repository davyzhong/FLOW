# FLOW 综合定位与方法论对照

## 一、FLOW 是什么（再确认）

**FLOW = Finance Intelligence OS / AI 财务经营分析平台**

- **目标用户**：中国企业内部财务分析师 / 战略 BP / 经营分析团队 / CFO 办公室
- **核心场景**：基于公开财报 + 反向解析 + 指标字典，做"经营快照 / 同业对标 / 杜邦拆解 / 财务健康评估"
- **数据基础**：14 份反向解析财报、670 条事实、167 个会计科目、49 个通用指标、15 个物流行业指标
- **部署形态**：本地化 / 私有化（数据敏感），开源（Apache / MIT），API + 静态资料库 + 看板 Widget 三种产品形态

## 三、FLOW 的差异化定位（核心结论）

### 1. 经营分析专门化（vs 通用 BI）

| 维度 | FineBI（最直接竞品） | FLOW（差异化） |
| --- | --- | --- |
| 数据源 | 任意（灵活） | 反向解析财报 + 事实库（精确） |
| 指标体系 | 用户自建 | **预制指标字典（49+15）** + 167 科目 + 治理版本 |
| 行业模板 | 通用 | **专门面向财报分析 / 物流行业** |
| 杜邦分析 | 用户自拖 | **三因子 + 五因子 + 二级子项** 内置 |
| 财务健康评估 | 无 | **6 维度评分卡** 内置 |
| 覆盖矩阵 | 无 | **指标 × 公司 × 期间 全景** + 缺口标注 |
| 报告生成 | 模板 + 数据 | **静态站 + Widget + 在线系统** 三态 |
| 数据更新 | ETL | **P5 反向解析** + 标准化事实库 |

### 2. 数据透明 + 可解释（vs AI 黑盒）

- **FineBI / 通联 / 通用 BI**：用户可看到数据，但口径定义 / 转化逻辑散落在 SQL / 配置中
- **AlphaSense / Hebbia**：AI 给答案，但"为什么" 难解释
- **FLOW**：每个数字都可溯源到
  - 具体 PDF 文件 + SHA-256
  - 具体抽取的科目事实（item_id / role / value）
  - 具体指标字典（metric_code + 定义 + 取数规则）
  - 具体覆盖矩阵（哪些单元格计算了 / 哪些缺）
- 这是中国监管 / 审计 / 财务 BP 真正需要的"可解释"

### 3. 私有化 + 中文会计准则 + 中文报表（vs 海外 SaaS）

- **Wind / AlphaSense**：云端，不支持中国本地化部署
- **FLOW**：本地化部署，支持 CAS / IFRS 双准则，中文报表原生处理

### 4. 数据科学 + 财务分析的融合（vs 单一领域）

- **OpenBB / FinRL**：量化研究 + 交易
- **FineBI / Superset**：通用 BI
- **FLOW**：财务分析 + 经营分析 + 数据科学（杜邦拆解 + 趋势预测 + 行业对标）

## 五、FLOW 当前的能力缺口（按优先级）

### 优先级 P0（直接影响核心价值）
1. **行业基准数据**：杜邦拆解没有行业对照表，对比无意义
2. **AI 问数**：所有头部竞品都在做，FLOW 没有
3. **更多数据源**：当前只有港股 5 公司 + 14 份财报，覆盖太窄

### 优先级 P1（增强差异化）
4. **趋势分析**：单期 → 多期趋势 / CAGR / 同比
5. **同行业更多公司**：物流行业至少要有 5-10 家（中国外运 / 德邦 / 极兔 / 中通 / 韵达 / 申通 / 圆通）
6. **DCF 估值 / 经济利润（EVA）**：McKinsey 范式
7. **情景分析 / 敏感性**：杜邦拆解的动态版本
8. **行业模板市场**：FineBI 经验 → FLOW 物流 / 电商 / SaaS 模板
9. **拖拽式 dashboard**：学习 Superset / DataEase

### 优先级 P2（拓展生态）
10. **AI 自动写 MD&A**：基于事实库 + LLM 自动生成经营分析报告文字版
11. **PDF / PPTX 报告导出**：基于指标体系生成可下载报告
12. **实时告警**：指标异常自动推送（飞书 / 企微 / 邮件）
13. **嵌入到第三方系统**：Widget 能力扩展
14. **BSC / 战略地图 / 五力**：战略分析框架
15. **行业 benchmark**：每个行业一份对标数据

## 六、风险与挑战

| 风险 | 描述 | 缓解策略 |
| --- | --- | --- |
| 数据护城河不足 | FLOW 14 份财报 vs Wind 35,000+ 家公司 | 专注垂直行业（物流 / 电商 / SaaS），做深 |
| AI 玩家碾压 | AlphaSense 估值 $10B，FLOW 资源有限 | 走开源 + 私有化 + 本地化路线，不与 SaaS 头部对打 |
| 反向解析准确率 | PDF 抽取误差导致指标失真 | 显式标注覆盖缺口，让用户知道哪里可信 |
| 杜邦通用 vs 行业特殊 | 银行 / 地产 / 物流杜邦不同 | 按行业定制版本（FLOW 已选物流） |
| 法规 / 监管变化 | 中国会计准则修订 | 跟踪最新 CAS / IFRS 更新 |
| 数据合规 | 公开财报 vs 内幕信息 | FLOW 严格只用公开披露 + 标注来源 |
| 用户教育 | 杜邦 / 五力 / BSC 学习曲线 | 提供教学示例（已部分做）+ 长桥 / 长江商学院合作 |
