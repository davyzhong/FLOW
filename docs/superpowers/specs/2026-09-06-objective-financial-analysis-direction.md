# FLOW 客观财务分析产品方向与阶段验收规格

日期：2026-09-06。状态：方向已由用户在本次讨论确认；实施细节按总计划分工作包细化。

## 1. 产品目的

最终服务企业内部财务分析；当前受内部数据不可得的现实约束，以公开财报建设和验证产品。公开财报是正式保留的数据入口。公开报表和未来企业账务/预算/业务明细通过不同适配器进入共享的财务语义、指标、证据与发布体系。

推进顺序为：客观数据与客观分析 → 有证据的原因分析和推断 → 改善方案与行动。当前只承诺第一阶段。客观分析包括趋势、结构、比率、可复算的数学分解；数学贡献不代表业务因果。利润下降可计算，竞争加剧等解释须额外证据。没有足够细项时不得制造价格/数量/结构分解。

## 2. 范围与约束

- 保留 D040 查阅级会计知识与取数映射，不建设总账记账系统。
- CAS 与 IFRS 分开记录准则及有效期间；管理层调整指标保留企业口径和调节，不把所有非 GAAP 指标都直接等同于 IFRS 18 定义的 MPM。
- 保留 D045 双轨共享底座；当前优先财务轨客观能力，经营轨保留定义与只读演示，主观归因与改善后置。
- 保留 D047 默认推荐结构与行业标准校准，不要求用户逐项审核全部指标；涉及企业自定义政策和适用性时记录明确选择。
- 标准、行业惯例、企业披露、模型假设分别管理；公式依赖、勾稽关系、统计关联、预测假设不能混为一类。预测与情景模型留后续阶段。
- 四表一注是目标信息结构；报告只重现已披露、已核验的内容。缺少权益变动表或附注明细时显式缺失，不能声称完整重建，也不从汇总财报倒造分录。
- 当前公开数据版本的完成不以取得企业内部数据为前置；真实企业适用性必须另行试点后才能声称验证。

## 3. 客观基础的五条验收链

1. 数据：每项值有来源文件哈希、页/表/行或等效定位、单位币种、期间、主体、合并范围、准则与版本；空值不等于零。
2. 口径：每个启用指标有定义、适用条件、取数规则、公式版本、精度与缺失处理；平均/期末、单季/累计、年化、重述均明确。
3. 计算：确定性计算；展示层不另建财务公式；同一输入及定义产生相同结果；新定义不改写旧快照。
4. 追溯：报告数字和事实陈述可追到计算与源数据；修订、复核、发布和影响范围可查询。
5. 验证：独立于抽取器生成逻辑的参考答案、内部勾稽、跨文档披露、跨格式一致性与未适配样本共同验证。

## 4. 阶段出口

公开数据版本：用户能在浏览器完成支持范围内的上传、核对、更正、计算、复核和导出；至少三家基线样本加两份未预先适配的留出报告（含一家新公司、一份新期间），保留所有失败和缺失。发布范围内关键数字与独立答案在预先登记的披露精度容差内全部一致、无未解释关键差异；覆盖率以全部目标项目为分母，不能仅报告通过的锚点。

企业内部数据版本：前期用明确标注的合成数据检验科目余额/预算接口和期间泛化；后续取得授权脱敏数据后验证真实映射、对账、细维度分析及业务价值。公开财报试验不能替代该项。
