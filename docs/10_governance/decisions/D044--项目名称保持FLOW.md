# D044 项目名称保持 FLOW

- 状态（原文）：有效；用户于 2026-09-06 确认。（映射为 accepted）

- 状态（原日志）：有效；用户于 2026-09-06 确认。
- 决定：项目工程名与工作名称保持 **FLOW**，不改名；正式品牌释义仍未决（沿用 D004 未决项）。
- 曾被考虑：FICO。否决理由：FICO 即 Fair Isaac Corporation（费埃哲，NYSE: FICO），全球最知名的信用评分与金融决策分析公司，与本产品同行业同品类，存在直接商标冲突且搜索不可见；SAP 语境中 FICO 还指 FI/CO 财务模块合称。用户听取该证据后决定保留 FLOW。
