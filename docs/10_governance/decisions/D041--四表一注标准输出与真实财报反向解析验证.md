# D041 四表一注标准输出与真实财报反向解析验证

- 状态（原文）：有效；用户于 2026-09-05 在 D040 基础上补充提出（两条要求，同日确认纳入）。（映射为 accepted）

- 状态（原日志）：有效；用户于 2026-09-05 在 D040 基础上补充提出（两条要求，同日确认纳入）。
- 决定：
  1. **分析标准**：财务分析基于客观财务视角，依据会计法规和会计准则；系统以标准「四表一注」（资产负债表、利润表、现金流量表、所有者权益变动表 + 附注）为基准输出物，指标分析建立在报表项目取数之上。对象模型相应新增「报表项目（StatementLineItem）」，取数链补全为「业务 → 分录 → 科目 → 报表项目 → 指标」；附注本期定位为披露项目清单 + 取数标注，不做全文生成；
  2. **验证方式**：开展真实财报反向解析验证实验——选取典型互联网公司/物流公司的当年度与当季度财报导入系统，系统据此重建「四表一注」并生成完整财经分析报告，再与公司已发布财报逐项比对，以比对结果作为准确性承诺的验证证据；差异分级为口径差异 / 解析误差 / 披露缺失，全部留痕归档。
- 边界：实验仅使用公司公开发布的财报；本实验是验证手段，不替代 Pilot Phase 2 脱敏真实数据试点，两者证据合并后优先决定 V1.1 范围；不改变任何已冻结契约与 D016/D028/D031/D033/D037 边界。
- 落地：正式规格 `docs/superpowers/specs/2026-09-05-flow-metric-dictionary-design.md` 第 1、3.6、8、10 节；实施排入 P3（报表项目落库）与 P5（验证实验）。
