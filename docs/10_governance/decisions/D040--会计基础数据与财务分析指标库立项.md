# D040 会计基础数据与财务分析指标库立项

- 状态（原文）：有效；用户于 2026-09-05 逐项确认（调研归档见 `02_research/original/07–09`，设计草案见 `02_research/synthesis/2026-09-05-会计与财务指标知识库_设计草案.md`）。（映射为 accepted）

- 状态（原日志）：有效；用户于 2026-09-05 逐项确认（调研归档见 `02_research/original/07–09`，设计草案见 `02_research/synthesis/2026-09-05-会计与财务指标知识库_设计草案.md`）。
- 决定：在 D039「准确性优先的财务分析」定位下，新建两样基础能力——会计基础数据（会计准则 / 会计科目 / 会计分录）与财务分析指标库（数据字典 + 指标计算与勾稽关系）；系统必须可查询、可更改、可观测、可使用。
- 逐项确认：
  1. 会计基础数据做**查阅级 + 取数映射**（科目/分录/准则知识 + 科目到指标取数的映射），不做核算级总账；核算级留待脱敏试点证据；
  2. 准则覆盖面为 **CAS + IFRS 对照**（IFRS 至少覆盖 MPM 管理层业绩指标等关键概念与口径对照）；
  3. 指标库初始规模为**通用 40 指标 + 物流行业 15 指标**，宁精勿滥；
  4. 指标库建成后，`flow.metrics.logistics.v1` **迁移为库内的行业指标集版本**，保持全系统单一口径来源；
  5. 推进节奏：与 Pilot Phase 2 安全部署及脱敏真实数据试点**并行**。
- 边界：本立项不修改任何已冻结契约；不绕过 D016（AI 不创造数字）、D028/D033（不可变快照消费边界）、D031（确定性分析输出）、D037（审批资格）。指标库的变更采用版本化（新口径版本 + 旧版本保留），与已发布快照不可变原则一致。
- 后续：依据设计草案编写正式规格与实施计划，经用户批准后进入实施。
