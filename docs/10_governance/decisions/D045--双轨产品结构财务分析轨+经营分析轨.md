# D045 双轨产品结构：财务分析轨 + 经营分析轨

- 状态（原文）：有效；用户于 2026-09-06 确认（「现在要设计落地双轨架构，并按照这个来修改整个系统和项目」）。（映射为 accepted）

- 状态（原日志）：有效；用户于 2026-09-06 确认（「现在要设计落地双轨架构，并按照这个来修改整个系统和项目」）。
- 决定：系统是**一套底座、两条轨道、两类受众**：
  1. **财务分析轨**（面向 Finance BP）：现有驾驶舱、Investigation、报告中心、报表分析（四表一注）、指标库，是当前建设主体；
  2. **经营分析轨**（面向经营/业务管理者）：与财务轨共享数据接入、标准数据中间层、指标语义与确定性引擎、证据/复核机制和界面体系，**区别仅在数据定义**（经营侧指标目录、数据契约与分析策略按轨道版本化扩展）；
  3. 两轨数字同源：同一指标快照身份链，不允许两套口径各自计算。
- 推进顺序（用户同日确认）：(a) 短期优先把财务分析轨全部功能与报告做完；(b) 经营分析轨不放弃既有积累，先在双轨架构下做小 demo；(c) 已有可用功能在双轨架构下同步归位。
- 取代与修订：
  - **D010 的单角色限定被取代**：恢复双受众，但以「双工作区」而非简单双角色页面实现；
  - **D039 的范围限定被修订**：经营分析从「未来扩展」变为并行第二轨；D039 的核心约束（准确性优先、确定性引擎、事实/判断/假设分离、AI 不创造数字）继续适用于两条轨道；经营分析轨的主观归因内容在未有证据治理前不得进入正式输出。
- 边界：双轨不引入新的计算引擎、不复制数据中间层；经营分析轨 demo 只读消费已发布快照，不产生新的 Finding/报告资格。
