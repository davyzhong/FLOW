# D043 报表可视化与图形化分析要求

- 状态（原文）：有效；用户于 2026-09-05 在 D041 基础上补充提出。（映射为 accepted）

- 状态（原日志）：有效；用户于 2026-09-05 在 D041 基础上补充提出。
- 决定：抽取/生成的「四表一注」必须具备高质量可视化呈现（不只罗列表格）——利润表瀑布图、资产负债结构图与期末/期初对比、现金流三类活动柱状与现金桥、权益变动桥、附注披露卡片；指标之上必须提供图形化分析——构成环形图（饼状）、柱状对比图、多指标趋势图、杜邦依赖分解等，图形类型清单在 P3 实施时与用户逐页确认。
- 边界：所有图形是同一冻结报表项目/指标快照的投影，图形层不得重算或修饰数字（D016/D028/D033 不变），图形与表格数字同源、可逐点溯源。
- 落地：规格 6.1 节；可视化由 P5 报告视图 `docs/implementation/p5/sf_2026q1_report_view.html` 承载（顺丰 2026 一季报真实数据：KPI 卡、五季度真实趋势、利润瀑布、结构环形、现金流同比、四表全量表，构建期做闭合校验）；指标库评审台总览提供入口链接，不重复建设图表实现；2026-09-06 起该图形语言整合进系统界面：`/statements` 报表分析页经 typed API 渲染落库的抽取数据（迁移 0011）。
