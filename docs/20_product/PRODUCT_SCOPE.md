# 产品范围

> 2026-09-13 起按 D052/D053 的目标结构组织：三层两模块。下列"已实现能力"不变，归属到新结构；"目标态"能力未实现前不得对外宣称。

## 目标结构（D053）

1. **可见的专业治理底座**：财务事实与会计科目定义、指标/公式/维度/差异分解、分析方法/证据规则/置信度规则、企业字段映射/管理口径/报告配置、知识来源/版本/变更记录。这些是外显产品功能：用户可查看任何数字如何计算、某条结论采用了什么规则、哪些是平台标准、哪些是企业配置。
2. **共享分析底座**：数据接入/识别/映射/校验/对账；确定性财务计算与标准差异分解；AI 探索性计算及程序复算；Finding/证据链/假设/追问/置信度；分析型 AI 与 CFO 角色 AI；报告版本/审核/冻结/导出。
3. **两个独立产品模块**：
   - **企业内部分析工作台（最终目标产品）**：持续存在的企业分析空间，按月创建分析周期，组织财务、预算、比较、应收、回款和现金数据；主交互为"工作流为主、对话为辅"（收集资料 → 识别与映射 → 校验与对账 → 自动标准扫描 → 推荐重点 → 深入调查 → 补充证据 → 分析型 AI 生成专业版 → CFO 角色 AI 生成管理层版 → 经分专员一次终审 → 正式发布）。
   - **公开财报分析模块（先行成熟底座）**：读取财报、附注、定期报告、公司官方材料及分级外部资料；拥有独立入口、规格、验收和模块 workstream/backlog 视图，但不另建可执行总路线图，也不再定义内部工作台的用户流程。

内部工作台实施前必须先发布向后兼容的 Financial Facts Contract V2（或等价扩展合同）及安全/权限子规格；具体字段、权限矩阵和验收协议以[战略重构设计](../superpowers/specs/2026-09-13-flow-strategic-reset-design.md)为准。

## 已实现能力（保留，归属共享底座与公开模块）

1. **数据与事实**：来源登记与财报抽取（B01–B05）、事实合同与勾稽、Excel 工作簿画像/映射/清洗/对账/发布。
2. **指标与计算**：指标库 v1.1（64 条）、客观快照与冻结、确定性分析原语、四表一注阅读。
3. **分析与复核**：四问工作台、Investigation 证据链、Finding/Evidence/Conclusion、追加式审阅事件。
4. **报告与发布**：报告中心（多格式发布）、经营六主题快照与 /operations 概览（O4）、Copilot（约束回答）。
5. **横切**：单用户认证与会话、对象存储与发布登记、结构化日志（U8-C）、CI 门禁。

## 不含（PRODUCT_BOUNDARIES 的范围侧摘要）

总账/记账系统、BI 看板化、AI 写作工具、行动任务管理（首版）、自动因果结论、伪造缺失事实、企业多租户 SaaS/计费/SSO、AI 绕过人工发布、把数学分解当业务归因。
