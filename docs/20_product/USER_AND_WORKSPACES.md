# 用户与工作区

## 目标态角色（D052/D054）

| 角色 | 产品责任 | 首版权限边界 |
|---|---|---|
| 经分专员 | 核心操作者、例外处理者、最终发布责任人 | 管理企业空间和月度周期；核对关键证据；一次终审发布 |
| Finance BP | 数据和业务背景提供者 | 受限轻量入口：上传文件、补充资料、回答证据问题、查看退回原因；不进入完整分析工作台 |
| 分析型 AI | 主要分析生产者 | 调用确定性工具、组织调查、形成 Finding 和财务专业版 |
| CFO 角色 AI | 管理层视角审查者（AI 角色，非人工审批节点） | 质疑证据、判断重要性、压缩细节、生成管理层版；不得改变事实或提升证据等级 |
| CFO | 首要阅读者 | 阅读最终报告；不作为系统发布的必经人工节点 |
| 管理层/业务负责人 | 最终价值承接者 | 主要消费发布的交互报告或派生版本 |
| 财务规则负责人 | 正式规则治理者 | 审批影响正式计算的企业级规则变更 |

## 目标态工作区（D053）

- **企业内部分析工作台（最终目标产品）**：每家部署企业拥有一个持续存在的企业分析空间，按月创建独立分析周期，积累映射、口径、偏好与历史分析。当前按公有云企业单租户部署，服务该企业多个经分专员和 Finance BP；不是多租户 SaaS。
- **公开财报分析模块**：独立入口与导航，面向公开材料分析；不定义内部工作台的用户角色。
- 两模块共享专业底座与指标快照身份链；数字同源（原 D045 边界继续适用于共享底座）。

## 当前实现（未变，如实标注）

- 现有页面 `/data`、`/statements`、`/metric-library`、`/reports`、调查与四问工作台、`/operations` 仍按历史双轨结构组织；主导航和工作流的大规模改造在 U8 收口后的边界重构阶段进行（D053 执行顺序）。
- 认证模型：单用户密码 + 会话 + 服务端 Bearer（无多角色/租户承诺）。
