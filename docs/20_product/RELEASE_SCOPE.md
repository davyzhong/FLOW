# 发布范围（按 D053 执行顺序）

## 阶段 0：U8 收口（当前）

- 完成真实存储完整旅程、HTTPS 部署拓扑、统一部署验收，形成完整、可运行、可恢复的现有版本。
- U8 期间不进行核心数据模型、主导航和月度工作流的大规模代码改造；战略文档治理可并行。

## 阶段 1：冻结版本并重构边界（U8 完成后门禁）

- 冻结 U8 完成版本；建立共享专业底座、公开财报模块、内部工作台的清晰模块边界与独立规格。
- 先发布向后兼容的 Financial Facts Contract V2（或等价扩展合同）以及安全、RBAC 和审计子规格，并通过角色拒绝、规则审批分权与 AI 无发布权限门禁。
- 旧 U9/U10 不机械续跑：按 D053 重新裁决保留、改写、合并或取消。

## 阶段 2：公开财报模块 C 级出口

- 分析主体：阿里巴巴（FY2019–FY2026，HKEX 官方披露）+ 菜鸟（招股书申请版本 IFRS）。
- 出口标准：自动完成公开材料接入、事实计算、自动 Finding、证据分级、分析型 AI、CFO 角色 AI、交互式报告、人工终审、冻结与导出；并通过[战略重构设计 §14.1](../superpowers/specs/2026-09-13-flow-strategic-reset-design.md#141-公开模块-c-级出口协议)的冻结样本、零严重事实错误、100% 正式数字可复算/可追源、独立盲评等量化门槛。
- 已发布能力见 CAPABILITY_MAP implemented 区。

## 阶段 3：企业内部月度分析工作台（最终目标产品）

- 范围：持续企业分析空间、月度分析周期、Finance BP 轻量提交入口、企业配置、历史学习、专业版 + 管理层版分层报告。
- 硬依赖：内部数据授权、U8 安全/部署收口、公开模块 C 级出口后的共享底座。

## 阶段 4：四级验证

物流样板端到端（物流供应链为第一验证样板，不是长期行业边界）→ 专业经分评审 → 与人工报告和工作量对照 → 授权脱敏真实企业数据最终验证。最终验证采用至少一家企业连续三个完整月度周期、同输入人工基准、独立盲评和全量人工工时记录；量化协议见[战略重构设计 §14.2](../superpowers/specs/2026-09-13-flow-strategic-reset-design.md#142-最终真实企业验证协议)。最终门槛任一项未达到，不自动扩大产品范围。

**发布纪律**：公开模块不等待内部数据；内部适用性必须独立完成真实试点才可宣称（D049）；AI 不绕过人工发布，交互式报告是权威母版，其余格式是派生物（D052/D054）。
