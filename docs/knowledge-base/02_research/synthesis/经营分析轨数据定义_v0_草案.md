## 2. 经营轨定位

- 受众：经营/业务管理者（总经理、事业部/经营单元负责人、运营负责人）；
- 问题域（`wiki/经营分析 (Business Analysis).md`）：财务分析回答「发生了什么」，经营分析回答「为什么及怎么办」——动因、过程、前瞻；
- 与财务轨关系（D045）：共享数据接入、标准中间层、确定性引擎、证据/复核机制与界面体系；**仅数据定义分轨**；数字同源，不另起计算引擎；
- 经营轨独有约束：凡涉及业务假设的主观归因，必须显式标记为「假设」，不得与确定性事实混排（沿用 D031/D039 约束）。

## 3. 维度模型草案

通用维度（数据熊语料高频出现，可直接迁移）：

| 维度 | 取值示例 | 说明 |
| --- | --- | --- |
| 组织 | 集团 / 事业部 / 经营单元 / 子单元 / 工厂 / 仓库 / 班组 | 与菜鸟「经营架构树」三层（事业部=预算考核层 EBITA 口径 → 经营单元=预算编制层 → 子单元=毛利口径）对应 |
| 区域 | 华东 / 华南 / 华北 / 华中 / 西南 / 西北 / 东北 / 海外 | |
| 产品 | 产品线 / 服务产品 / SKU / ABC 分类 | 菜鸟「服务产品」= 收入记账的基本管理颗粒度（仓配一体/干线运输/进口直邮/纯仓/纯配等 L1 目录） |
| 客户 | 战略 / 重点 / 成长 / 一般 / 长尾；信用等级 AAA–BB | 客户分层 + 信用双维 |
| 渠道 | 直销 / 经销 / 电商 / 代理 / 项目 | |
| 订单 | 订单号级明细 | 支撑负边际订单识别 |
| 时间 | 月 / 周 / 日 / 13 周滚动 | |
| 分档 | 账龄、库龄、效期（0-30 / 31-60(90) / 91-180 / 180+） | 应收与库存共用分档语义 |

菜鸟参照（事实依据）：主数据分两类（1 类稳定：OU/客户/供应商/产品/支出事项；2 类欠稳定：事业部/经营单元/子单元/成本管理单元）；核算底线维度 = 收入至少到 OU/事业部/经营单元/客户/产品/合同，成本费用加成本管理单元与标准支出事项（`wiki/主数据应用要求.md`）。

## 4. 指标目录草案（按域分组）

口径凡有菜鸟真实目标值的，标注菜鸟基线作为参照（不是 FLOW 的目标值）。

### 4.1 增长与收入

| 指标 | 口径/公式 | 来源 |
| --- | --- | --- |
| 营业收入及完成率 | 实际 / 目标 / 差距 / 达成概率 | 数据熊驾驶舱系列 |
| 收入增长来源瀑布 | 老客增长 + 新客贡献 + 价格变化 + 产品结构 + 渠道贡献 − 客户流失 | 美的体系、总经理驾驶舱 |
| 有效商机 / 赢单率 | 商机分层 A/B/C；赢单率 = 签约 ÷ 有效商机 | 集团经营分析驾驶舱（路径拆解） |
| 订单收入比 | 新增订单 ÷ 确认收入 | 总经理驾驶舱（1.14 / 105.8% 实例） |
| 客户集中度 | TOP5 / TOP10 客户收入占比 | 集团运营驾驶舱（58.6% / 42.5% 实例） |
| 客户生命周期 | 新增 / 活跃 / 沉睡 / 流失 + 转化率 | 同上 |
| 平均销售周期 | 商机到签约天数 | 路径拆解（42 天实例） |

### 4.2 盈利

| 指标 | 口径/公式 | 来源 |
| --- | --- | --- |
| 经营利润与利润差距桥 | 价格 / 销量 / 结构 / 材料成本 / 效率改善 分解 | 综合经营总览 |
| 单位贡献毛利拆解 | 销售单价 − 材料 − 人工 − **物流成本** − 销售费用 | 集团运营驾驶舱（物流成本为正式拆解项） |
| 多维盈利矩阵 | 产品 × 客户 × 区域 × 渠道；盈利产品占比、亏损客户数、负边际订单数 | 多维盈利分析页 |
| 利润三口径 | 会计利润 / 财务利润（EBIT/EBITDA/FCF）/ 管理利润（剔一次性损益） | `wiki/利润三维度模型.md` |
| 盈亏平衡与安全边际 | 固定成本 ÷ 综合边际贡献率；安全边际率 | `wiki/盈亏平衡分析模型（数据熊高级版）.md` |

### 4.3 运营与交付

| 指标 | 口径/公式 | 来源 |
| --- | --- | --- |
| 准时交付率 OTD | 准时交付订单 ÷ 应交付订单（物流 3 项之一） | 15 行业 225 指标；各驾驶舱目标 95–96% |
| 平均交付时间 | 出库到签收平均时长 | 15 行业 225 指标 |
| 破损率 | 破损件 ÷ 总件数 | 15 行业 225 指标；亦为菜鸟计费优惠阶梯要素 |
| 预测准确率 / 采购满足率 / 齐套率 / 排产达成率 | 供应链计划链四指标 | 集团经营分析驾驶舱（82.5% / 93.7% / 88.2% / 90.1% 实例） |
| 产能利用率 / OEE / 一次合格率 | OEE = 可用率 × 性能效率 × 质量率（72.6% = 88.2% × 85.6% × 96.2% 实例） | 生产运营分析报告 |
| 人均产值 / 人效 | 收入、毛利 ÷ 平均人数；分部门拆解与归因 | 人效分析报告模板 |
| 延期原因帕累托 | 关键物料 / 产能冲突 / 质量返工 / 客户变更 / 物流延误 | 订单交付路径页 |

缺口（语料零命中，待补来源）：妥投率、车效（车辆周转/满载率）、仓效（库容利用率/拣选效率）、线路维度（干线/末端）、公里成本。

### 4.4 库存与供应链

| 指标 | 口径/公式 | 来源 |
| --- | --- | --- |
| 库存金额 / 周转天数 / 周转次数 | 分原材料/在制品/产成品/商品/备件分段周转 | 集团库存分析驾驶舱（76 天 / 4.8 次实例） |
| 呆滞 / 超储 / 缺货 / 临期库存 | 库龄五档 + 风险类型（呆滞/超储/缺料/临期）+ 影响金额 | 同上 |
| 库存健康度四象限 | 周转天数 × 销售增速（备货/健康/清理） | 同上 |
| 库存变化归因瀑布 | 期初 + 规模增长 + 价格因素 + 结构变化 + 降库举措 = 期末 | 经营看板 |
| FIFO 执行率 | 批次级先进先出执行率（92.6% 实例） | 批次效期质量页 |

### 4.5 现金与回款

| 指标 | 口径/公式 | 来源 |
| --- | --- | --- |
| 现金转换周期 CCC | DSO + DIO − DPO（美的实例 29 天 = 45+52−68） | 美的体系 |
| 回款率 / 回款预测 | 当期回款 ÷ 当期赊销；未来 8 周概率加权预测 | 总经理驾驶舱 |
| 应收账龄与逾期 | 账龄五档 × 客户分层；逾期率、高风险客户数 | 应收分析模型（01_财务分析） |

### 4.6 业财运营质量（菜鸟 CFO 域事实基线，供经营轨「系统健康」板块参考）

## 5. 报告结构范式（经营轨月报/专题报告模板）

各来源报告结构高度一致，归纳为：

1. **核心结论页**：总体判断 / 目标差距 / 经营质量 / 行动闭环（每页一个结论句式）；
2. **指标驾驶舱**：KPI 卡（实际 / 目标 / 差距 / 同比 / 环比 / 状态灯）+ 累计缺口；
3. **滚动预测**：年度目标 × 乐观/基准/保守三情景（各带前提假设）；
4. **收入结构**：产品线 / 渠道 / 客户三维拆解 + 增长来源瀑布；
5. **利润分析**：利润形成瀑布 + 净利率对比 + 多维盈利矩阵；
6. **成本与降本**：成本差异瀑布（标准成本/材料价格/耗用/人工/制造费用/产量）+ 降本路线图（各带预计贡献）；
7. **专题页**（按需）：库存 / 应收 / 人效 / 交付 / 质量；
8. **问题闭环**：TOP 问题清单（影响金额 / 责任人 / 期限 / 状态机：分析中→改善中→待验证→已关闭）。

菜鸟「八条地铁线」可作为经营轨流程覆盖度的对照清单：定价 / 应收 / 应付 / 财资 / 经分 / 财务风控 / 业财控制 / 合规（`wiki/业财一体化八条地铁线模型.md`）。

## 6. 数据契约扩展方向（不改动已冻结契约）

经营轨落地时按版本化新增，候选工作表（评审后定稿）：

- `10_商机漏斗`：线索/商机/报价/签约（阶段、金额、负责人、预计成交日）；
- `11_交付履约`：订单级交付节点（计划/实际、延期天数、延期原因、OTD 分母分子）；
- `12_库存快照`：物料 × 仓库 × 批次（库龄、效期、质量状态、冻结标记）；
- `13_人效`：部门 × 人数 × 人工成本 × 产出；
- 物流专营指标对应的作业数据（妥投/车次/装载）——**来源缺口未补前不定稿**。

## 7. 评审与落地方式

1. 用户对本草案逐项评审（沿用指标库评审台模式：纳入 / 待定 / 剔除）；
2. 评审通过后版本化为 `config/metrics/operations_dictionary_v1.yaml` 等系统配置；
3. 经营轨 demo 页（`/operations`）逐步从「复用财务轨快照投影」切换到经营轨自己的数据定义；
4. 反向生成验证（D046 步骤 3）：用公开财报/管报逆向生成经营分析报告，与本目录口径比对。
