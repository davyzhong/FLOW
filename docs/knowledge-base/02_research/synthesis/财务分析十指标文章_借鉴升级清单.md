## 2. 一句话判断

这篇文章的知识价值**不在指标定义**（十个指标的公式与 `flow.metric_dictionary.v1` 通用 40 指标高度重合），而在两件事：

1. **一个最小问题骨架**：「有没有增长 → 增长有没有带来利润 → 利润占用了多少资产和资金 → 资产和资金有没有转化为现金」——四个问题串起十个指标，是指标库的"最小可用子集"组织方式；
2. **逐指标的拆解路径与质量联查**：每个指标给出"公式 → 拆解方向 → 质量判断 → 常见误区"四段式，其中增长质量联查（收入增速 vs 应收增速剪刀差）、净现比趋势、ROE 分母机械抬升识别等，是可直接转化为 FLOW 确定性检查规则的分析模式。

它与 FineBI 看板借鉴（六问题域专题组织）互为粗细两层：四问骨架是"上层叙事线"，六问题域是"专题展开层"。

## 4. 升级/更新列表

按「直接吸收 / 改造后吸收 / 归入后续阶段」三档列出，每项标注对应工作包与边界。

### U1 · 四问问题骨架并入 D01 客观分析目录（直接吸收）

文章的四问主线是比 FineBI 六问题域更粗一层的叙事骨架。D01 定义 `objective_finance_v1.yaml` 时，以四问作为目录顶层组织（增长/盈利/资产资金占用/现金转化），六问题域作为各问下的专题展开层；底层仍引用同一事实与指标版本。已随本清单并入 D01 工作项说明。

### U2 · 「核心十指标」默认视图（直接吸收，落点 D01/D02）

通用 40 指标是字典，不是首屏。建议在指标定义上增加 `essential: true` 类标记（或由 D01 的分析主题直接引用十指标子集），让驾驶舱/报告提供"最小核心集"默认视图，40 指标作为完整字典入口。避免首屏指标平铺，也避免另建第二套口径——标记是元数据，不是新指标。

### U3 · 指标治理：费用率候选与既有净现比复用（2026-09-07 订正）

按 D047 和下一阶段 P01/P03 处理，一项候选新增、一项复用检查：

- **期间费用率** =（销售费用 + 管理费用 + 研发费用 + 财务费用）/ 营业收入；口径裁决依据建议取国资委/CPA 惯用口径，备选"三费"（不含研发）口径并存标注；依赖边为四项费用科目 → 报表项目 → 指标；
- **净现比（复用 `ocf_net_profit_ratio`，不新增同义项）** = 经营活动现金流量净额 / 净利润；需声明期间匹配语义（同期流量/流量）与单期波动的解读限制；与既有现金流量比率为并列关系，不互相替代。

### U4 · 增长质量联查作为确定性检查候选（改造后吸收，落点 D01/C05）

文章的"收入增长 15%、应收增长 40% = 赊出来的增长"是典型的可证伪联查。FLOW 化改造：不采用文章的经验表述作阈值，而是定义确定性计算（收入增速 − 应收增速的剪刀差值、净现比多期趋势），只呈现偏差与方向，不贴"健康/危险"标签；阈值如需预警，必须走"阈值来源 + 适用范围 + 版本"治理（与 FineBI 借鉴的边界一致）。候选形式：分析 playbook 或 D01 联查规则。

### U5 · 毛利率三因子拆解与既有 PVM 对齐（改造后吸收，落点 C05）

文章的"价格 + 成本 + 结构"毛利拆解与 Phase 5 已有的 Revenue V/P/M playbook 同构。不新建第二套分解引擎；在 D01 定义毛利专题时，把 V/P/M 范围从收入扩展到毛利（价格因素、单位成本因素、产品结构因素），公开财报阶段可算性由适用性规则裁决（需要分产品收入/成本明细时显式降级）。

### U6 · 净利率逐层还原链与利润构成区分（直接吸收方向，落点 D01）

"毛利率 → 营业利润率 → 净利率逐层落差去向 + 主营/非经常/会计估计三分"与 FLOW 既有的利润桥和 MPM 调节研究（EY IFRS 18，09 号资料）一致。D01 定义利润专题时把"逐层还原 + 构成区分"作为标准下钻路径；非经常性损益口径需对照 CAS/证监会披露规则，不能照搬文章的通俗分类。

### U7 · ROE 分母机械抬升提示（改造后吸收，落点 C03 指标元数据）

"大额分红/回购/亏损侵蚀会机械抬高 ROE"是指标解读层面的口径提示，适合沉淀为指标定义的 `annotation`/`interpretation_notes` 元数据（v1 已有 caliber/provenance 字段体系），而不是新建检查逻辑。同样适用于总资产周转率的重大资产处置场景。低成本，随 v1.1 治理一并处理。

### U8 · 应收账龄/集中度与存货结构（归入内部数据轨，G 轨）

文章对应收（账期内 vs 逾期、账龄、前五大客户集中度）和存货（原材料/在产品/产成品/呆滞 + 库龄/动销/订单覆盖）的细分拆解，超出公开财报数据可得性——披露口径只有总额。这部分与[经营分析轨数据定义草案](经营分析轨数据定义_v0_草案.md)的账龄库龄分档设计一致，标记为内部数据试点（G 轨）需求，不进入公开财报版本的客观分析目录。

## 5. 不吸收与边界

1. **无来源的行业阈值与"健康/危险"标签**：文章多处给经验判断（如"净现比连续 3–5 年 ≥ 1"），FLOW 中只能作为方向参考；正式预警阈值必须有权威来源与版本（沿用 FineBI 借鉴分析的既有边界）；
2. **"一次讲清"式简化不进入正式口径**：文章为教学目的合并了口径细节（如 ROE 分母用"平均净资产"带过期间语义、期间费用率行业差异），正式定义以指标目录的公式与口径裁决为准；
3. **FineBI 产品能力描述**：文内推广段落描述的"FineBI 看板能力"属于营销语境，不做产品能力断言依据（FineBI 能力边界以看板借鉴分析 §1 的公开文档核验为准）。
