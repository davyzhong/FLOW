## 结论

这篇展示的是 FinRoom（宋老师）生态的成品工具《多产品·多约束盈亏平衡测算模型》（单机版 HTML）：本量利（CVP）测算 + 线性约束下的产品组合优化 + 瓶颈诊断（TOC）+ 敏感性分析 + 场景中心 + 计划实际偏差。**对 FLOW 当前财报主线（U 系列）没有可执行的新动作**——其测算内核全部依赖变动/固定成本拆分、资源消耗矩阵、约束表达式，均为 L2/L3 内部数据（D050 分层下财报期不可算）；最优组合求解与瓶颈投资建议属行动层（D049 后置）。**它的价值是 O5/L2 期「经营测算模块」的完整产品蓝图**：登记为 D050 L2/L3 层参照，届时按其模块清单做 FLOW 化取舍。

## 一、工具能力还原（模块级）

| 模块 | 能力 | FLOW 对应层 |
|---|---|---|
| 数据建模 | 数据中心（完整性/错误分类/校验）、产品参数（负边际贡献警示、参数审计）、成本中心（变动/固定/现金三分、重复归属预警）、资源矩阵、约束中心（线性表达式、冲突检测、可行性状态） | L2/L3；intake 质量门与版本审计 FLOW 已有同构物 |
| 经营测算 | 产品组合三结构对比与调整影响预览、场景中心（五方案参数矩阵+利润影响瀑布）、盈亏平衡四模式（含可行性判决赛）、最优组合求解（五种目标） | L2 测算内核；「另存新场景不覆盖基准」= FLOW 版本化纪律同频 |
| 决策分析 | 瓶颈诊断（瓶颈边际价值=影子价格、放宽模拟 ROI、缓解建议带预期区间）、敏感性分析（龙卷风图/双因素矩阵/目标反算）、计划与实际（偏差拆解瀑布、预警闭环带责任人） | L2/L3 + 行动层（预警闭环与驾驶舱借鉴 #7 同构） |
| 输出管理 | 报告中心（模板/配置/多格式导出/导出版本记录）、模型设置（口径三选、精度、求解器、审计日志、备份恢复点） | 报告与治理层 FLOW 已有更强对应（冻结链/迁移/审计） |

## 二、判断与取舍

1. **不可照搬的**：最优组合求解与瓶颈放宽投资建议是行动层决策支持（D049：行动闭环不在当前范围）；CVP 的变动/固定拆分在公开财报口径下不可靠（财报成本不按性态披露，D050「缺失不补造」）——FLOW 财报期不做盈亏平衡测算。
2. **同频佐证（无动作）**：「应用结果另存新场景不覆盖基准」= FLOW 版本化/不可变纪律；重复归属预警 = intake 质量检查；参数审计日志 = 指标库审计；保本可行性 typed 判定（可实现/待修复）= typed 状态合同风格。
3. **L2 期蓝图价值（登记候选 #12）**：届时经营测算模块的取舍清单——CVP 测算（成本性态拆分来自成本中心数据）、约束建模（线性表达式+冲突检测）、瓶颈边际价值（影子价格指导性表述，仍属测算而非决策）、敏感性分析（假设驱动，须与客观分析分离并标注假设，对应 D049「预测依赖与确定性公式分开」）、计划-实际偏差（预警闭环挂行动层）。
4. 负边际贡献产品警示：若分部/产品线披露足够（L1 边际情形），FLOW 可算「分部毛利为负」提示——已由 D050 OP-3 收入结构主题覆盖边际情形，无新增。
