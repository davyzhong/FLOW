## 结论

这篇 18 页卡片文（FinRoom/宋老师，2026-09-06）是三篇借鉴中**与 FLOW 纪律契合度最高**的一篇：其核心主张——「差额分解只解释金额构成，不证明业务原因」「证据状态分三级、行动档位随之分级」「每向下追一层都要补业务证据」——与 FLOW 已实现的 C14 相关性≠原因、U5 证据门禁、Finding 四要素完全同频；它新增的有效载荷是**差异分解的口径约定**（分解顺序、维度边界、分摊陷阱）和**报告四步叙事结构**，直接强化 U5/U6 的报告合同。行动层四页（行动卡/净效益测算/反事实验证/滚动预测）是 D050 L4 行动层迄今最好的外部参照，登记候选。

## 一、内容还原（四步框架）

**看现状 → 找问题 → 挖原因 → 定行动**，每步输出成为下一步输入（总体判断 → 优先问题清单 → 原因判断与证据链 → 行动安排与验收标准）；报告的终点是支持选择（继续投入什么、调整什么、接受什么代价）。

1. **看现状**：先明确本次经营决策再选指标（扩张/盈利修复/现金承压三情境各有判断焦点）；统一口径（组织范围、时点、含税返利一致）+ 四种标尺（预算/同比/环比趋势/可比标杆）互相补充；「先处理口径差异，再解释经营差异」。
2. **找问题**：影响×持续性四象限定优先级（优先进入决策/及时处理与复盘/例行监控/观察累积风险），叠加紧迫性（再等一个月失去什么）与可干预程度（接下来能改变哪个环节）；「异常百分比决定显眼程度，经营影响与紧迫性决定优先级」。
3. **挖原因**：利润瀑布做差额分解（预算→收入规模→毛利率→费用→实际），**分解口径约定**——先按预算毛利率计算收入影响，再按实际收入计算毛利率影响；沿业务层级下钻（公司→业务线→产品组→客户→订单），每层回答一个专属问题；**「差额分解解释金额构成；业务证据支持原因判断」**；证据三检查（可比性/时间顺序/反向验证）→ 结论三态（已证实/有支持/待验证）→ 行动三档（直接推进/有限试点/继续核查）。
4. **定行动**：行动卡（牵头人/周程交付/协同分工/验收要求，试点前确认目标与停止条件）；净效益测算（静态增利 − 销量副作用 − 执行费用 = 净改善，且不直接冲减历史利润缺口）；执行与结果分别验证 + 反事实判断（可比客户组/分批试点，对照「没有这项措施会怎样」）+ 副作用观察；滚动预测（更新预测 = 原预测 + 当期可兑现净改善，按确定性三态处理）；复盘闭环（下一次分析从上次行动的结果开始，固化有效做法进日常规则）。

## 二、与 FLOW 的对照判断

### 同频验证（FLOW 已有，文章佐证其行业共识）

| 文章主张 | FLOW 对应 |
|---|---|
| 「差额分解尚未证明业务原因」 | C14 相关性≠原因；U2 原语输出仅为提示 |
| 结论三态（已证实/有支持/待验证）→ 行动三档 | Finding 证据资格 + 四要素结论 + U5 主观门禁 |
| 「先处理口径差异，再解释经营差异」 | I12 口径标签登记制；D01 口径强制 |
| 每向下追一层补业务证据 | Evidence 链与调查页源记录 |
| 执行、结果、有效性分别验证 | Investigation 审阅状态机 |
| 收益去重、利润与现金分别预测 | 期间/口径/粒度合同（P02） |

### 新增有效载荷（建议采纳）

1. **差异分解口径约定**（挂 U6 渲染规范 + C08 口径参数）：①分解顺序显式声明（先量后价：收入影响按预算毛利率、毛利率影响按实际收入——顺序不同结果不同，必须随图标注）；②固定成本分摊变化 ≠ 实际耗用增加（量价分离警示）；③同一订单多项优化收益需去重。FLOW 的 C08 守恒桥目前只锁定「总和守恒」，应把分解顺序作为显式口径参数并随图表渲染（与驾驶舱借鉴 #2 口径附表合并落地）。
2. **报告四步叙事结构**（挂 U5/U6 章节合同）：客观报告章节按「现状判断 → 优先问题 → 原因与证据链 → 行动安排与验收标准」组织，每章输入为上一章输出；与 D050 OP-5 五环闭环、Investigation 流对齐。客观报告（U5 门禁内）只承载前三步的客观部分，行动章仅在主观证据达标后进入。
3. **问题优先级模型**（登记候选，挂 U7）：影响×持续性四象限 + 紧迫性 + 可干预程度的排序框架——工作台问题列表排序的候选语义（客观可算部分：影响金额、恶化持续期；「可干预程度」属主观判断，U5 门禁后）。
4. **行动层参照**（登记候选，挂 D050 L4/O5/U9）：行动卡、净效益测算（静态 vs 净改善、不冲减历史缺口）、反事实验证（可比组/分批试点）、滚动预测（净改善按确定性三态进入预测）——这是 L4 行动层迄今最完整的外部范式，内部数据授权后启用。

### 边界

- 教学演示数据；下钻层级（业务线→产品组→客户→订单）在公开财报场景不可得（L1 只有汇总与分部），属 L2 内部层范式。
- 「可干预程度」「策略性低毛利核查」等含业务判断，按 D049 属推断/行动层，不入客观报告。
