## 一、产品定位（原文完整摘录）

> 驾驶舱是一套面向**集团及多业务单元**的企业级经营管理平台，以**"看结果、找差距、查原因、定措施、验效果"**为主线，统一整合财务、销售、采购、生产、库存、人力及项目等经营数据。
>
> 内置**数据中心**，支持 Excel、CSV、JSON 等多种格式的数据导入导出，并提供字段映射、数据校验、批次管理和质量监控。
>
> **指标支持指标名称、公式、口径、单位、目标值及预警阈值灵活配置**，实现统一口径和版本留痕。
>
> 可按组织、产品、客户、区域、渠道和项目等维度联动筛选，**逐层下钻至业务明细**，将经营异常转化为问题、责任人、改善措施和完成期限，形成从数据洞察到经营改善的完整闭环。

要点拆解：
1. 与资料一最大的不同：**数据源不止财务报表**，而是财务+销售+采购+生产+库存+人力+项目全经营域；导入格式多了 JSON 和 API 的概念。
2. 明确提出**指标中心**：指标 = 名称+公式+口径+单位+目标值+预警阈值，带版本管理（版本留痕）。这就是用户想做的"指标定义系统"的现成参照。
3. 主线五步：**看结果 → 找差距 → 查原因 → 定措施 → 验效果**，页面组织完全按这条链走。

## 二、整体信息架构

**左侧导航（12 个模块）**：经营总览 / 目标与预测 / 收入增长 / 盈利质量 / 现金资金 / 应收回款 / 库存供应链 / 运营效率 / 风险预警 / 问题闭环 / 数据中心 / 指标中心。

**每页右上角统一按钮**：`查看明细`（下钻业务明细）+ `导出报告`；顶部全局筛选（期间/区域/产品/渠道/事业部/单位等）随页面主题变化。

**演示数据背景**：集团总部 + 华东/华南/华中/西南/海外 5 个事业部（工厂维度：华东/华南/华中/西南/海外工厂）。2026年8月：营业收入 12,680 万元（同比 +8.4%，预算完成率 96.8%），经营利润 1,128 万元，经营现金流 860 万元。年度收入目标 156,000。

**统一版式**：页面标题 + 一句定位副标题 → 4~5 张 KPI 卡 → 2~4 个分析图表 → 1~3 个清单/责任表 → 右下角"管理结论"卡（结论 + 行动按钮如"创建××改善任务"）。

## 四、资料一 vs 资料四：两个驾驶舱的定位差异

| 维度 | 资料一：集团财务智能驾驶舱 | 资料四：总经理经营决策驾驶舱 |
|---|---|---|
| 视角 | 财务总监（CFO） | 总经理 / 经营会 |
| 数据域 | 4 张中国财务报表（利润表/资产负债表/现金流量表/权益变动表） | 财务 + 销售 + 生产 + 库存 + 人力 + 项目全经营域 |
| 模块组织 | 按财务主题（盈利/费用/资产负债/营运资金/现金流/风险/合并） | 按经营闭环（结果→差距→原因→措施→验证） |
| 独有能力 | 集团合并（抵销桥、管理口径vs合并口径）、13周资金预测、杜邦分析 | 滚动预测+情景测算、风险预警中心、问题闭环（收益验证）、指标中心 |
| 形态 | 单机版、单文件、离线 | 企业级平台（多数据源、多用户、审批流） |
| 管理语言 | 偿债/周转/含金量/抵销 | 目标缺口/根因/责任人/验证收益 |

**共同基因**（两个产品都体现，= 我们的产品的底线设计）：
1. 每页底部一句"经营结论/管理结论"；
2. 瀑布图做差距归因（预算→实际的因子分解）；
3. 风险/异常直接挂"影响金额 + 责任人 + 截止日"；
4. "较预算/较目标"与"同比"双对比；
5. KPI 卡 → 图表 → 清单 → 结论 → 一键生成任务的固定页面范式。
