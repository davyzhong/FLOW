## 逐卡转录

### 卡 1（06_1.png）：标题页

企业内经营分析和财务分析的区别——**同一组数据，两套视角，一套经营闭环**。

- 经营分析侧三大对象：业务运营（效率与过程）、销售与增长（规模与结构）、产品与客户（价值与组合）
- 财务分析侧三大对象：财务报表（结果呈现）、现金流与偿债（安全与流动）、投资与回报（价值创造）

### 卡 2（06_2.png）：01 经营分析管业务动作，财务分析守资本安全

七个维度的总对照表（左列经营分析，右列财务分析）：

| 维度 | 经营分析 | 财务分析 |
|---|---|---|
| 目标 | 推动业务增长，提升运营效率，达成经营目标 | 评估财务健康，防范风险，保障资本安全 |
| 服务对象 | 业务团队、运营团队、管理层 | 投资人、董事会、财务团队、监管机构 |
| 报表顺序 | 先业务后财务：业务数据 → 管理报表 → 财务报表 | 先财务后业务：财务报表 → 业务数据 → 分析洞察 |
| 颗粒度 | 细粒度：到客户、产品、渠道、区域、时间 | 粗粒度：到公司、事业部、合并口径、期间 |
| 指标体系 | 多维度、过程性指标为主，关注驱动因素 | 结果性、财务指标为主，关注结果与结构 |
| 指标联动 | 因果驱动：从动作到结果，找杠杆、抓重点 | 逻辑勾稽：从结果看结构，识别风险与约束 |
| 分析结果 | 产生行动清单，明确责任人、优先级与时间表 | 形成判断结论，明确风险等级与管控建议 |

底部示例：净利润 +6000 万 vs 经营现金流 −2000 万——**同一组数据，不同的决策终点：财务分析判断是否健康；经营分析推动谁来改变**。

### 卡 3（06_3.png）：02 目标不同——经营分析推动改善，财务分析保障安全

- 经营分析：弥补毛利缺口 3000 万 = 渠道优化 +900、产品提价 +700、促销提效 +500、生产改善 +500、采购降本 +400
- 财务分析：弥补资金缺口 5000 万 = 压降库存 +2000、催收应收 +1500、优化账期 +800、补充融资 +700
- 企业价值提升 = 经营改善（收入增长、毛利提升、费用提效、运营效率）+ 财务稳健（现金安全、融资结构、投资回报、资本风险）

金句：**分析不是为了证明数字正确，而是为了让下一步决策更正确**。

### 卡 4（06_4.png）：03 服务对象不同——经营分析服务一线作战，财务分析服务资本决策

- 同一组经营数据 → 经营分析 → 业务部门、渠道负责人、产品线负责人、经营班子 → 业务动作与经营改善
- 同一组经营数据 → 财务分析 → 老板、财务与资金、股东、投资人 → 资本配置与风险判断
- 报告配比：经营分析报告 = 问题与动作 75% + 财务结果与风险 25%；财务分析报告 = 盈利、现金与资本 85% + 业务解释 15%
- 三种关注：业务关注「差距在哪里？谁来改？」；管理层关注「需要什么资源？」；资本方关注「是否安全？回报如何？」

金句：**让每个对象看到自己必须采取的行动**。

### 卡 5（06_5.png）：04 看报表的顺序不同——经营从利润追原因，财务从资产看安全

- 经营分析阅读顺序：利润表（差距在哪里）→ 资产负债表（占款在哪里）→ 现金流量表（是否转化为现金）
- 财务分析阅读顺序：资产负债表（家底与杠杆）→ 现金流量表（流动性与偿债）→ 利润表（盈利质量）
- 案例（12 个月趋势）：净利润持续增长 500→750 万，应收天数 45→72，库存天数 62→88，经营现金流 700→−800 万；链条为「利润保持增长 → 应收与库存上升 → 经营现金流转负」

金句：**看报表的顺序，就是分析者心中问题的顺序**。

### 卡 6（06_6.png）：05 颗粒度不同——财务看到科目，经营必须下钻到业务单元

- 净利润 +6000 万 → 经营现金流 −2000 万的瀑布：应收增加 −5000、存货增加 −4000、预付款增加 −800、其他经营资产 −500、应付增加 +1800、折旧等非现金 +500
- 财务分析：看到科目金额；经营分析：找到业务单元与责任人——
  - 应收 → 客户 / 区域 / 销售负责人
  - 存货 → 产品线 / SKU / 采购计划
  - 预付款及其他 → 供应商 / 项目 / 费用责任人
  - 对冲因素 → 应付账期 / 折旧 / 非现金项目

金句：**汇总数字负责报警，细分数字负责破案**。

### 卡 7（06_7.png）：06 指标丰富度不同——经营分析要解释转化过程和生产效率

- 收入侧转化漏斗：销售线索 10 万 → 有效线索 3 万（转化率 30%）→ 报价客户 1.2 万（40%）→ 成交客户 3000（25%）→ 收入 9000 万
- 成本侧生产成本三级拆解：单位生产成本 100→112 元/件（+12.0）= 原材料 +6.5（主材价格 +3.0、材料损耗 +2.0、配方结构 +1.5）+ 设备 OEE +3.2（开动率 85%→82%:+1.4、性能效率 90%→87%:+1.0、良品率 96%→94%:+0.8；OEE 73.4%→67.1%）+ 人工 +2.3（单位工时 +1.2、加班成本 +0.7、人员结构 +0.4）

金句：**财务指标描述结果，经营指标解释结果如何形成**。

### 卡 8（06_8.png）：07 经营分析——收入、毛利、应收、库存需连起来看

- 产品线增长质量诊断（示例）：A 产品线收入增 30%/毛利 38%/应收 105 天/库存 92 天 → 待改善（高增长、高占款）；B 产品线 18%/31%/30/40 → 优质成长；C 产品线 5%/42%/20/28 → 优质现金牛；D 产品线 25%/22%/90/110 → 问题产品
- 结论：B、C 低占款增长质量更高；D 低毛利、高应收、高库存应优先整改
- 经营价值链因果模型：收入增长（价格 × 销量 × 商品结构）→ 毛利贡献（收入 × 毛利率 − 变动成本）→ 营运资金占用（应收 + 存货 − 应付）→ 经营现金流（毛利 − 费用 − 营运资金增量）→ 投入资本回报率 ROIC
- 经营风险链条：放宽账期 / 压货促销 → 应收与库存天数上升 → 折价、退货与坏账 → 现金恶化、ROIC 下降

金句：**没有毛利和现金支撑的收入，不是增长，而是把风险推迟确认；优质增长 = 收入增长 + 合理毛利 + 低资金占用**。

### 卡 9（06_9.png）：08 分析结果不同——经营分析必须压实责任，形成行动闭环

- 现金释放计划：现金缺口 −2000 万 → 去库存 +3000、催收应收 +3000、投放优化 +1000、采购账期 +1500 → 改善后 +6500 万
- 行动表（示例）：产品线去库存（产品负责人，1800 万，60 天）；区域催收（销售负责人，1500 万，45 天）；投放优化（市场负责人，1000 万，30 天）；采购账期（供应链负责人，1500 万，60 天）
- 行动闭环：发现问题 → 定位业务单元 → 确定责任人 → 制定动作 → 跟踪复盘

金句：**没有落实到责任人的分析，只是信息；形成行动闭环，才是管理**。

## 与 FLOW D039 的对照

本文对两种分析的切分方式与 D039 的定位判断互相印证，且划线位置基本一致：

1. **切分维度一致**。文章用「目标 / 服务对象 / 报表顺序 / 颗粒度 / 指标体系 / 指标联动 / 分析结果」七个维度区分两者；D039 按数据依赖与确定性切分——财务分析 100% 依赖财务数据、结论客观确定；经营分析还需经营侧数据、含主观业务假设判断。文章卡 2 的「结果性财务指标 vs 多维过程性指标」「逻辑勾稽 vs 因果驱动」与这一判断同构。

2. **FLOW V1 已实现的 playbook 落在财务分析一侧，且文章佐证了它们的确定性**。收入 V/P/M（价格 × 销量 × 结构）分解正是文章卡 8「收入增长 = 价格 × 销量 × 商品结构」的价值链第一环；履约 R/V/E、利润桥、应收账龄对应卡 5/卡 6 的「从结果看结构、识别风险与约束」和科目级勾稽。这些分解只用已收集的财务数据即可计算，属于 D039 保留范围内的「客观报告性经营数量」。

3. **文章划出的经营分析专属部分，恰好是 D039/决策日志列为「未来」的部分**：
   - 转化漏斗（线索 → 报价 → 成交）、OEE 三级拆解（卡 7）依赖经营侧过程数据——即「订单级经营明细」扩展；
   - 行动清单 + 责任人 + 期限 + 跟踪复盘（卡 9）对应决策日志未来事项中的 Issue/Action/Owner/Deadline/Outcome 闭环；
   - 「下钻到客户/产品/渠道/区域/时间」（卡 2 颗粒度行）中的维度模型 FLOW 已具备（organization / customer_segment / logistics_product / region），但目前只承载财务事实，不承载业务过程事实——这与 D039 的边界一致。

4. **一条有用的产品语言**：「汇总数字负责报警，细分数字负责破案」（卡 6）与「分析不是为了证明数字正确，而是为了让下一步决策更正确」（卡 3）可作为后续报告文案与产品叙事的参考表述；「优质增长 = 收入增长 + 合理毛利 + 低资金占用」（卡 8）与 FLOW 增长质量类 playbook 的口径一致。

结论：本文不改变 D039 的任何决定，而是从行业方法论一侧确认了「先做确定性财务分析、经营分析作为明确未来扩展」的路线合理性。
