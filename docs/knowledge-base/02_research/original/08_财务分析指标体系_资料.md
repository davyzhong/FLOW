## 1. 四大能力指标体系（国内教科书 / 实务主流框架）

财务分析指标按四大能力组织，部分框架增加第五维「现金流」：

### 偿债能力

| 指标 | 公式 | 要点 |
|---|---|---|
| 流动比率 | 流动资产 ÷ 流动负债 | 经验参考约 2；过高可能资金闲置 |
| 速动比率 | (流动资产 − 存货) ÷ 流动负债 | 更严格口径，参考约 1 |
| 现金比率 | 货币资金 ÷ 流动负债 | 最保守口径 |
| 现金流量比率 | 经营活动现金流量净额 ÷ 流动负债 | 现金保障程度 |
| 资产负债率 | 负债总额 ÷ 资产总额 × 100% | 参考 40%–60%，行业差异大 |
| 产权比率 | 负债总额 ÷ 所有者权益 | 资本结构 |
| 利息保障倍数 | 息税前利润 ÷ 利息费用 | >3 较安全 |
| 长期资产适合率 | (所有者权益 + 长期负债) ÷ 非流动资产 | 长期资本与长期资产匹配 |

### 营运能力

| 指标 | 公式 | 要点 |
|---|---|---|
| 应收账款周转率 | 营业收入净额 ÷ 平均应收账款 | 回款效率；账期拉长要警惕 |
| 应收账款周转天数 | 360 ÷ 应收账款周转率 | 平均回款期 |
| 存货周转率 | 营业成本 ÷ 平均存货 | 库存管理效率 |
| 流动资产周转率 | 营业收入净额 ÷ 平均流动资产 | |
| 固定资产周转率 | 营业收入净额 ÷ 平均固定资产 | |
| 总资产周转率 | 营业收入净额 ÷ 平均资产总额 | 整体资产运营效率 |
| 应付账款周转率 | 采购成本 ÷ 平均应付账款 | 对供应商账期占用 |

### 盈利能力

| 指标 | 公式 | 要点 |
|---|---|---|
| 毛利率 | (营业收入 − 营业成本) ÷ 营业收入 × 100% | 产品先天赚钱能力；下滑常先于净利率，是竞争加剧早期信号 |
| 营业利润率 | 营业利润 ÷ 营业收入 × 100% | |
| 净利率（销售净利率） | 净利润 ÷ 营业收入 × 100% | |
| 净资产收益率 ROE | 净利润 ÷ 平均净资产 × 100% | 股东视角核心回报 |
| 总资产收益率 ROA | 净利润 ÷ 平均总资产 × 100% | |
| 总资产报酬率 | (利润总额 + 利息支出) ÷ 平均资产总额 × 100% | |
| 成本费用利润率 | 利润总额 ÷ 成本费用总额 × 100% | |

### 发展能力

| 指标 | 公式 |
|---|---|
| 营业收入增长率 | (本期营收 − 上期营收) ÷ 上期营收 × 100% |
| 净利润增长率 | (本期净利润 − 上期净利润) ÷ 上期净利润 × 100% |
| 总资产增长率 | (期末总资产 − 期初总资产) ÷ 期初总资产 × 100% |
| 净资产增长率 | (本期净资产 − 上期净资产) ÷ 上期净资产 × 100% |

解读通则（各来源一致）：

- 单期看结构、多期看趋势；连续三期下滑比单期低于均值更值得警惕；
- 指标须结合行业特性横向对比，重资产与轻资产企业不可比；
- 多指标交叉验证（如高资产负债率 + 低利息保障倍数 = 偿债风险高）；
- 异常须追溯业务环节，避免单一指标误判。

## 2. 杜邦分析体系

核心公式与分解：

- ROE = 净利润 ÷ 平均净资产
- 三因素分解：ROE = 销售净利率 × 总资产周转率 × 权益乘数
  - 销售净利率 = 净利润 ÷ 营业收入（盈利能力）
  - 总资产周转率 = 营业收入 ÷ 平均总资产（运营效率）
  - 权益乘数 = 平均总资产 ÷ 平均净资产（财务杠杆）
- 扩展分解：
  - 销售净利率可再拆为毛利率、费用率、税率；
  - 总资产周转率可再拆为流动资产（存货、应收、现金）与非流动资产（固定资产）周转率；
  - 五步分解法在税务负担、利息负担维度进一步细化。

历史与局限：

- 20 世纪初由杜邦公司财务经理 Donaldson Brown 系统提出，后引入通用汽车；
- 局限：总资产与净利润口径不匹配、未区分经营与金融活动损益、仅依赖报表数据有短期导向、忽略现金流、行业差异不可生搬硬套。

## 3. 评级机构口径（联合资信：中国物流集团评级报告附件）

信用评级报告附件《主要财务指标的计算公式》是高度规范化的指标口径范本，摘录：

- 增长指标：n 年复合增长率 = [(本期 / 前 n 年)^(1/(n−1)) − 1] × 100%
- 经营效率：
  - 净营业周期 = 应收账款周转天数 + 存货周转天数 − 应付账款周转天数
  - 销售债权周转次数 = 营业总收入 ÷（平均应收账款净额 + 平均应收票据 + 平均应收款项融资）
  - 存货周转次数 = 营业成本 ÷ 平均存货净额
  - 总资产周转次数 = 营业总收入 ÷ 平均资产总额
  - 现金收入比 = 销售商品、提供劳务收到的现金 ÷ 营业总收入 × 100%
- 盈利指标：
  - 总资本收益率 = (净利润 + 费用化利息支出) ÷（所有者权益 + 长期债务 + 短期债务）× 100%
  - 净资产收益率 = 净利润 ÷ 所有者权益 × 100%
  - 营业利润率 =（营业总收入 − 营业成本 − 税金及附加）÷ 营业总收入 × 100%
  - EBITDA 利润率 = EBITDA ÷ 营业总收入 × 100%
  - 总资产报酬率 =（利润总额 + 费用化利息支出）÷ 平均资产总额 × 100%
- 债务结构：
  - 资产负债率 = 负债总额 ÷ 资产总计 × 100%
  - 全部债务资本化比率 = 全部债务 ÷（长期债务 + 短期债务 + 所有者权益）× 100%
  - 担保比率 = 担保余额 ÷ 所有者权益 × 100%
- 长期偿债：
  - EBITDA 利息倍数 = EBITDA ÷ 利息支出
  - 全部债务 / EBITDA
  - 现金短期债务比 = 现金类资产 ÷ 短期债务
  - 经营现金流动负债比 = 经营活动现金流量净额 ÷ 流动负债 × 100%

来源（S 级权威，中国货币网披露的评级报告原文）：
- 中国物流集团有限公司主体长期信用评级报告：https://www.chinamoney.org.cn/dqs/cm-s-notice-query/fileDownLoad.do?contentId=3379593&priority=0&mode=save

## 4. 对 FLOW 建设的提示

- 同一指标存在多口径（如净资产收益率：净利润 ÷ 平均净资产 vs 净利润 ÷ 期末所有者权益；营业利润率是否扣除税金及附加），指标库必须把「口径版本」作为一等属性；
- 评级机构公式附件是「指标卡片」的好模板：指标名、公式、计量单位、参考区间、数据来源科目；
- 杜邦体系证明指标间存在显式依赖图（ROE ← 净利率 / 周转率 / 权益乘数），与 FLOW 已有 `flow.metrics.logistics.v1` 的「14 条显式依赖边」设计一致，指标库应原生支持依赖关系存储。
