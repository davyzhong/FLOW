| p05.png | 05 | 经营链条四端：需求端（市场/客户/订单）→履约端（采购/生产/库存/交付）→价值端（收入/毛利/经营利润）→资金端（应收/经营现金流/融资需求）；上沿产品结构/价格政策/渠道策略/客户质量，下沿产能约束/交付能力/信用政策 |
| p06.png | 06 | **五层指标体系**：结果指标/结构指标/驱动指标/过程指标/风险指标，各层对应一个问题（经营得怎样/结果由什么构成/什么力量推动变化/动作是否执行到位/当前结果能否持续）；阅读路径：看结果→拆结构→找驱动→验过程→判风险 |
| p07.png | 07 | **五种经营关系**：因果（谁推动谁）/结构（哪部分贡献最大）/制约（哪个环节瓶颈）/平衡（改善是否以另一项恶化为代价）/时间（影响何时显现）；「同步变化不等于因果关系，平均改善不等于结构改善」 |
| p08.png | 08 | 收入→毛利联动：收入=销量×平均售价，毛利=销量×(售价−单位成本)；增量毛利四因子（销量规模/折扣提价/产品结构/单位成本）；优质/低效/亏损增长分级；「每增加一元收入增加多少边际利润」 |
| p09.png | 09 | 产销→库存联动：库存水位（正常/高龄/呆滞）；三信号（采购生产增速>销售增速→积压；库存下降+缺货率上升→备货不足；库存上升+交付率下降→结构错配） |
| p10.png | 10 | 收入→回款联动：订单→交付→收入→开票→应收→回款→经营现金流，断点（未开票/逾期/坏账）；三信号（应收增速>收入增速→增长质量下降；逾期增速>应收增速→信用风险上升；利润增长+经营现金流下降→资金被占用）；**「利润是观点，现金是真相」** |
| p11.png | 11 | 产能→成本联动：产能利用率 U 型曲线（低效区/经济运行区/拥堵区）；「示意图，具体阈值因企业而异」；产能利用率不是越高越好 |
| p12.png | 12 | 费用三分：维持型（当期）/增长型（中期，ROI/获客成本/回收期）/能力型（长期，里程碑/未来产出）；「不要用同一把剪刀削减所有费用」 |
| p13.png | 13 | 利润→现金→负债联动：有利润不等于有现金（库存应收预付款占用→经营现金流下降→融资缺口→借款财务费用→净利润挤压恶性循环）；现金转换周期公式；「增长速度超过现金承受能力，企业可能越增长、越缺钱」 |
| p14.png | 14 | 综合案例：收入+15%/毛利+2%/净利润−18%/经营现金流−25% 的七环传导链（降价赊信获客→低毛利订单→产能承压→加班外协→库存应收上升→现金流下降→借款费用上升）；表面结论 vs 真正问题（增长质量下降，利润与现金被同时透支） |
| p15.png | 15 | **六步法**：锁定结果差距→拆解业务结构→量化因素贡献→追踪业务过程→交叉验证因果→形成改善闭环；输出 = 一个结论 + 一条链路 + 三组证据 + 一套动作 + 一组验证指标 |
| p16.png | 16 | 终点：看数（发生了什么）→联动（为什么发生）→决策（接下来改变什么）；单个指标描述状态，指标联动解释经营 |
