## 1. Apache Superset（安装文档）

用户入口：http://superset.apache.org/installation.html（实际重定向至 Docker Compose 安装文档）

要点：

- **官方推荐部署方式为 Docker Compose**：单机起一组容器（superset 本体 + metadata PostgreSQL + Redis + 可选 Node 前端构建）；文档同时提供 Kubernetes（Helm）路径用于生产扩展；
- **compose 文件分层覆盖模式**：基础 `docker-compose.yml` 之上叠 `docker-compose-image-tag.yml`（钉版本）、`docker-compose-non-dev.yml`（生产化关闭 dev 特性）、`docker-compose-bootstrap.yml`（本地开发引导）等覆盖层，按场景组合而非改基础文件；
- **元数据库是命脉**：文档明确警告——Superset 的图表/看板/数据集/用户等全部元数据存在其 metadata database 中，**该库必须备份并精心运维**，丢失即丢失全部已构建的分析资产；
- **SECRET_KEY 纪律**：必须显式设置且多副本间一致，轮换不当会导致登录态/加密字段失效；密钥不入镜像、不入版本库；
- **缓存层**：Redis 既作缓存（chart/query cache）也作异步查询（Celery）broker，仪表盘性能与刷新解耦靠它；
- 产品形态：连接外部数据库的通用 BI——语义层是「dataset」（物理表 + 计算列 + 指标定义），图表/看板全部引用 dataset 而非裸 SQL（SQL Lab 才是裸查询区）。

来源：
- Superset 官方安装文档（Docker Compose）：https://superset.apache.org/docs/installation/docker-compose/
- Superset 官方安装总览：https://superset.apache.org/docs/installation/installing-superset-from-scratch/

## 2. Redash（官方 README；CSDN 文章为部署教程镜像）

用户入口：https://blog.csdn.net/diantun00/article/details/80968604（程序化抓取 404，改用官方 README；CSDN 文章内容为 Redash Docker 部署教程，与官方 setup 文档同构）

要点：

- **定位**：开源数据查询与可视化平台，让任何人（无论技术水平）使用数据；SQL 用户探索/查询/可视化/分享，其他人基于成果决策；
- **查询是一等公民**：每个可视化背后是可版本化的查询；支持**同行评审（peer review）**——查询和可视化可被组织内评审后复用；
- **数据源**：内置 35+ SQL/NoSQL 连接器（PostgreSQL、MySQL、MongoDB、ClickHouse、Elasticsearch、CSV/JSON 等），数据源 API 可扩展；
- **告警**：定义条件，数据变化满足条件时即时提醒（destination 可对接邮件/webhook 等）；
- **定时刷新**：按自定义间隔自动更新图表与看板（scheduled query refresh）；
- **REST API 覆盖全部 UI 能力**：UI 能做的操作 API 都能做（与 FLOW「浏览器只经 typed API」原则同向）；
- **部署**：开源版 Docker Compose（server / worker / postgres / redis 多容器）；BSD-2-Clause 许可证。

来源：
- Redash 官方 README（GitHub）：https://github.com/getredash/redash
- Redash 开源部署文档：https://redash.io/help/open-source/setup

## 3. FineBI（帆软产品页）

用户入口：https://www.fanruan.com/finectl/download-finebi（下载页需登录，程序化抓取 404；改用产品主页，架构级分析见 [FineBI 借鉴分析](../synthesis/2026-09-06-FineBI财务经营分析看板_架构借鉴分析.md)）

要点：

- **定位**：企业级自助式大数据 BI，核心是业务人员（销售/财务/人事/运营）自助分析，同时为 IT 减负；
- **四环节流程**：数据准备（多源接入 + Excel 导入）→ 数据编辑（可视化操作、无 SQL）→ 可视化（50+ 图表、联动钻取）→ 分享协作（多人协同仪表板、一键发布）；
- **与 FineReport 的关系**：同厂互补双产品——FineReport 是「IT 报表生产」（固定报表开发），FineBI 是「业务自助分析」（自由探索）；按业务能力分级赋能（入门图表/中级多维/高级复杂计算）；
- **企业治理特性**：按权限脱敏、全局水印、SQL 防注入；
- **性能宣称**：千万级数据秒级响应、10000+ 用户在线（营销口径，未见实测方法）；Spider 引擎自建索引实现抽取式分析。

来源：
- FineBI 产品主页：https://www.fanruan.com/finebi
- FineBI 下载入口（需登录）：https://www.fanruan.com/finectl/download-finebi
