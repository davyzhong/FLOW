## 一、报告的整体叙事结构（18 页）

这份 PPT 不是"指标罗列"，而是一篇**用数据讲的管理故事**，叙事主线：

**总述（P2-P3）→ 逐层归因（P4-P9：计划→设备→瓶颈→质量→成本→人效）→ 供应链与库存（P10-P11）→ 交付与安全（P12-P13）→ 损失量化与因果链（P14-P15）→ 行动方案（P16-P17：P0止损/P1稳定）→ 机制（P18：30/60/90天路线图）**

**每页固定三段式版式**：
1. **结论式大标题**（橙色竖条 + 一句完整判断，如"OEE降至72.6%，80%的缺口来自可用率和速度损失"）；
2. 标题下一行**副标题**（补充口径或限定）；
3. 左右分栏的证据图表；
4. 页面底部**蓝色"经营结论"横条**（✔图标 + 一句管理判断）。
5. 页脚统一：数据熊 出品｜2026年7月生产运营分析报告｜页码。

### P2 核心结论（images/02_2.png）
**标题**：产量实现增长，但交付、质量和成本没有同步改善。
**副标题**：增长是真实的，但被质量、交付和库存吃掉了。
**内容**：四个关键结果块——产量指数 102.6（环比+2.6%）｜准时交付率 OTD 91.8%（目标96%）｜一次合格率 FPY 95.1%（目标97%）｜单位制造成本 184.6 元/件（较预算+4.9%），配简短解释文字。
**经营结论**：产量增长没有同步转化为交付、质量与利润改善，7月处于"增产不增利"状态。

### P3 核心指标总览（images/02_3.png）
**标题**：六项核心指标全部指向同一问题：有效产出不足。
**内容**：6 张指标卡（实际 vs 目标）：
| 指标 | 7月实际 | 目标 |
|---|---|---|
| 生产计划达成率 | 95.6% | ≥98% |
| 排程达成率 | 88.7% | ≥93% |
| OEE | 72.6% | ≥75% |
| 一次合格率 FPY | 95.1% | ≥97% |
| 准时交付率 OTD | 91.8% | ≥96% |
| 单位制造成本 | 184.6 元/件 | ≤176 元/件 |
**经营结论**：增产没有带来等比例的有效产出与利润，问题出在计划稳定性、过程质量和瓶颈管理。

### P4 计划稳定性（images/02_4.png）
**标题**：产量增长2.6%，但计划稳定性下降正在制造额外成本。
**副标题**：7月增长更多来自追产，而不是计划效率提升。
**图表**：
- 左：6月与7月产量指数柱图（100 → 102.6，环比+2.6%）；生产计划达成率 95.6%、排程达成率 88.7% 两条进度条。
- 右：因果链条目卡：生产计划调整 **46次** → 急单、插单占比 **18%** → 平均换型时间 **78分钟** → 加班工时 **2,860小时** → 在制品环比增加 **14.2%**；底注"计划调整—换型增加—加班追产—在制积压"。
**经营结论**：继续依靠插单与加班追产，只会把需求波动转化为成本、质量和库存压力。

### P5 设备效率 OEE（images/02_5.png）
**标题**：OEE降至72.6%，80%的缺口来自可用率和速度损失。
**副标题**：全月非计划停机及等待合计96小时。
**图表**：
- 左：OEE 环形仪表 72.6%（目标 75.0%，差距 -2.4pct）；公式行：可用率 88.2%（目标92.0%）× 性能效率 85.6%（目标90.0%）× 质量率 96.2%（目标97.5%）= 72.6%。
- 右：**停机损失帕累托**（柱 + 累计占比折线）：换型与清线 28h（累计29%）｜设备故障 24h（54%）｜物料短缺 21h（76%）｜质量停线 13h（90%）｜其他 10h（100%）；标注"前三项占总停机时长76%"。
**经营结论**：改善顺序应先稳定计划与物料，再提升设备可靠性，最后优化运行速度。

### P6 产线瓶颈（images/02_6.png）
**标题**：B产品终检负荷达到104%，局部开机率掩盖全链条瓶颈。
**副标题**：非瓶颈工序提前生产，只会形成在制品等待。
**图表**：
- 左：工序流程负荷图：来料→加工→装配→焊接→**终检/测试（红色，负荷104%，全链条瓶颈）**→入库；图例：正常负荷（蓝）/接近满负荷（橙）/超负荷（瓶颈，红）。
- 右：三张数据卡：平均换型时间 78分钟/标准55分钟；E02设备故障停机 24小时/同类报警重复3次；B产品终检测试负荷 104%/在制品持续堆积。
**经营结论**：非瓶颈工序满负荷不会增加最终交付，只会把等待从设备前转移到在制品库存。（约束理论 TOC 的表述）

### P7 质量（images/02_7.png）
**标题**：一次合格率降至95.1%，质量问题正在同时侵蚀产能和毛利。
**副标题**：质量损失成本达到21.0万元。
**图表**：
- 左：四个 KPI：一次合格率 95.1%；过程不良率 3.8%；报废率 1.2%；质量损失成本 21.0 万元。
- 中：主要不良类型横条：核心部件尺寸偏差 31%｜换型参数设定不稳 24%｜装配/焊接缺陷 18%（橙框标注：**前三类累计73%**）；外观缺陷 14%；其他 13%。
- 右：质量损失构成环形图：报废材料 9.8万元（46.7%）｜返工人工 6.8万元（32.4%）｜分选/退货/加班 4.4万元（21.0%）。
**经营结论**：根因不在终检拦截，而在来料、首件、参数锁定和标准作业的过程预防失效。

### P8 单位成本（images/02_8.png）
**标题**：单位制造成本超预算8.6元/件，材料和固定费用贡献最大。
**副标题**：7月单位制造成本184.6元/件，较预算高4.9%。
**图表**：
- 顶部 4 KPI：实际成本 184.6 元/件｜预算成本 176.0 元/件｜不利差异 +8.6 元/件｜超预算 +4.9%。
- 左：**单位制造成本差异分解瀑布图**：预算 176.0 → 直接材料 +3.4 → 直接人工 +1.7 → 变动制造费用 +0.8 → 固定制造费用 +2.7 → 实际 184.6。
- 右：三类原因卡：材料差——紧急采购溢价、报废与返工损耗；效率差——单位工时超标、加班增加；固定费用差——产量未充分覆盖停机损失。
**经营结论**：成本超支并非单一采购涨价，而是计划、质量、设备和产量共同作用的结果。

### P9 人效与加班（images/02_9.png）
**标题**：加班工时增加30%，但人均合格产出反而下降4.1%。
**副标题**：加班没有同比例转化为有效产出。
**图表**：
- 左：**哑铃图**（实际●蓝 vs 目标▌黑，橙色差距线）：单位直接工时 1.72 vs 1.60 小时/件；加班工时 2,860 vs ≤2,200 小时；关键岗位技能覆盖率 78% vs ≥90%；人均合格产出 118 vs 123 件/人；单位综合能耗 8.6 vs 8.0 kWh/件。
- 右：加班为什么没有转化为有效产出（5 条）：等待物料（物料晚到或齐套不足，人员设备空转）；等待检验与返工（检验排队与质量问题返工占用大量时间）；重复换型与清线（频繁换型清线时长长，产出被非增值动作侵蚀）；设备异常补产（故障停机后通过加班补产）；瓶颈前提前生产（在瓶颈工序前过早生产，造成堆积与等待）。
**经营结论**：必须将加班拆分为需求增长、计划波动、质量返工和设备补产四类。

### P10 供应商（images/02_10.png）
**标题**：缺料停线21小时，核心风险集中在S02和S05。
**副标题**：供应波动正在同时影响交付、质量和采购成本。
**图表**：
- 左：**供应商风险矩阵**散点图（X=准时交付率 80%~100%，Y=来料一次合格率 90%~100%；象限：高风险/观察/重点改善/正常）：S02（84.0%/94.2%，高风险）、S05（87.5%/95.1%，高风险）、S03（92.0%/98.3%，重点改善）、其他供应商（95.8%/98.8%，正常）。
- 右：缺料停线 21 小时；损失合格产出约 170 件；紧急采购 23 批/32 万元；红条警示：**S02与S05贡献70%的来料不良**。
**经营结论**：供应商评价应由价格与到货，升级为价格、准时、质量和停线损失的总成本评价。

### P11 库存（images/02_11.png）
**标题**：库存增加11.0%，但关键物料仍短缺，库存配置出现失衡。
**副标题**：库存上升没有改善交付。
**图表**：
- 左：6月与7月库存结构对比堆叠柱（原材料/在制品/产成品）：6月 385+232+523=1,140 万元 → 7月 420+265+580=1,265 万元（环比+11.0%）；下方三条注释：原材料总额增加但关键物料仍缺；在制品增加但瓶颈无法消化；产成品增加但OTD下降。
- 右：4 张卡：库存天数 42 天；90天以上库龄 78 万元；慢动库存 126 万元；B产品瓶颈前在制品 108 万元。
**经营结论**：库存问题不是总量不足，而是关键料、一般料和瓶颈前在制品的结构错配。

### P15 因果链总图（images/02_15.png）
**标题**：7月不是多个独立问题，而是一条运营机制失配的因果链。
**副标题**：局部指标背后是订单、计划、生产、质量与交付的系统传导。
**内容**：九节点因果链流程图（两行，橙色箭头串联）：
订单变更与插单增加 → **计划冻结机制失效**（计划调整46次）→ 换型、缺料与设备等待（停机等待96小时）→ OEE下降（OEE 72.6%）→ 加班与赶工增加（加班2,860小时）→ **首件及过程控制弱化**（FPY 95.1%）→ 返工、报废与质量停线 → 库存结构失衡（库存+11%）→ 交付延期与单位成本上升（OTD 91.8%）。
**经营结论**：各部门若分别追求产量、采购价格和局部开机率，企业整体交付与利润仍可能恶化。

> 设计观察：这是整份报告的"灵魂页"——把前面每一页的指标串成一条因果链，展示"系统性归因"能力。我们的分析引擎若能自动生成这种因果链叙事，就是真正的"深入数据挖掘"。

### P18 30/60/90 天路线图与经营机制（images/02_18.png）
**标题**：从持续救火转向系统经营，形成订单到利润的闭环。
**副标题**：30/60/90天运营提升路线与三级经营机制。
**内容**：
- 三阶段卡：**0—30天 止损**（任务：稳定计划、质量围墙、设备检修、关键料保供、延期清理；结果：OTD恢复、FPY回升、停机下降）→ **31—60天 稳定**（任务：SMED、标准作业、供应商分级、技能矩阵、库存治理；结果：OEE≥76%、库存天数≤38天）→ **61—90天 优化**（任务：约束产能接单、S&OP、SKU成本、MES/OEE数据闭环；结果：订单—交付—利润闭环）。
- 三级经营机制：**每日15分钟**——处理缺料、设备、质量、瓶颈和当日交付异常；**每周60分钟**——冻结未来4周需求、产能、物料和客户承诺；**每月经营会**——审议交付、利润漏损、库存和能力建设。
**结语**：真正要解决的不是如何生产更多，而是如何以更少波动、更高一次合格率和更低库存，按承诺日期交付更有价值的订单。

## 三、这份报告值得我们产品复制的设计精华

1. **结论式标题**：每页标题就是一个判断句（含数字），读者只看 18 个标题就能获得完整结论——这就是"分析报告"区别于"数据报表"的地方。
2. **一页一问题**：P4 计划 → P5 设备 → P6 瓶颈 → P7 质量 → P8 成本 → P9 人效，每页只回答一个问题，证据链单页闭环。
3. **图表选型专业**：帕累托（停机原因）、瀑布（成本差异）、哑铃（实际vs目标5指标）、散点矩阵（供应商风险）、堆叠柱对比（库存结构）、流程负荷图（瓶颈）、因果链图（系统归因）——没有一张"装饰性图表"。
4. **钱本位收口**：P12 把延期折算成"11.5万毛利推迟确认"，P14 把全部运营问题折算成"42.6万利润漏损"并附口径说明。
5. **行动有验收标准**：P0/P1 每条行动都有责任人+期限+可量化验收标准，且明确"开会培训发通知不算完成"。
6. **时间维度三段式**：当月复盘（止损）→ 次月目标（稳定）→ 90天机制（优化），形成滚动的经营节奏。
