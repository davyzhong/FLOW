## 一、产品定位（原文完整摘录）

> 集团财务智能驾驶舱是一套面向集团型企业的**单机版财务分析工具**，可直接导入符合**中国财务报表格式的 Excel 或 CSV 数据**，自动完成字段识别、数据校验、指标计算及集团合并分析。
>
> 系统设置**集团总览、利润增长、盈利能力、费用、资产负债、营运资金、现金流、财务风险、集团合并和数据中心十大模块**，支持期间、组织口径、币种及累计、当月等条件联动筛选。
>
> 通过指标卡、趋势图、结构图、预警清单和管理建议，帮助管理层快速识别收入、利润、现金、周转及偿债风险，形成**"问题—原因—措施—跟踪"管理闭环**。
>
> 看板采用**单文件离线运行**，无需安装部署，数据保存在本机，兼顾使用便捷性、数据安全性和企业级分析深度，适用于月度经营分析、财务汇报及管理决策。

要点拆解：
1. **单机版、单文件、离线运行**——没有后端服务，整个驾驶舱是一个 HTML/JS 文件，数据存本机。这和我们预想的"后台数据处理系统 + 前台 Web"是两种截然不同的产品形态，值得重点讨论。
2. **数据入口是中国财务报表格式**（利润表/资产负债表/现金流量表/所有者权益变动表的标准 4 张表），用户只需要报表格式的 Excel，不需要自建数据仓库。
3. **十大模块**是按财务分析教科书式的主题划分的，不是按部门/业务划分。
4. **"问题—原因—措施—跟踪"闭环**：每个模块页面底部都有一条"经营结论"，让报表直接给出判断句，而不是只放数字。

## 二、整体信息架构

**左侧导航（10 个模块）**：集团总览 / 利润增长 / 盈利能力 / 费用分析 / 资产负债 / 营运资金 / 现金流 / 财务风险 / 集团合并 / 数据中心。左下角固定 logo"数据熊定制"。

**顶部全局筛选条（所有页面一致）**：期间（2026年7月）｜口径（集团合并口径）｜币种（人民币）｜累计/当月切换｜右上角"数据更新：2026-08-01 08:30"。

**页面统一版式**：标题 → KPI 指标卡行（6-8 张）→ 2~3 个大图表区块 → 2~3 个明细表/清单区块 → 页面底部"经营结论"蓝条（一句带判断的管理结论）。

**演示数据背景**：XX 集团，下辖制造A、制造B、贸易C、服务D、海外E 五个经营单元（子公司12家+事业部6家+参股公司2家，共20个主体、纳入合并6家）。2026年7月（累计口径）：营业收入 126,895 万元，同比 +12.6%。

### 页面 2｜利润与增长分析（images/01_2.png）

**8 张 KPI 卡**：营业收入 126,895 万元（同比+12.6%）｜毛利 38,458 万元（毛利额同比 +15.2%）｜毛利率 30.3%｜EBITDA 19,192 万元｜营业利润 16,879 万元｜净利润 9,674 万元（净利润同比 +13.1%）｜净利率 7.6%｜净利润预算完成率 92.1%。

**图表区**：
- **收入、利润与毛利率趋势**（1-7月）：收入柱（同总览）+ 净利润线 + 毛利率线（28.6% → 27.2%...按月 28.6 / 29.1 / 29.4 / 29.7 / 29.9 / 30.1 / 30.3），右轴为百分比。
- **净利润预算差异析**：瀑布图。预算净利润 10,500 → 收入影响 +800 → 毛利率影响 -1,100 → 费用影响 -600 → 其他影响 +74 → 实际净利润 9,674。正向绿色、负向橙色，虚线连接。
- **收入结构**：环形图。核心产品 56.1%、成长产品 25.7%、服务收入 13.8%、其他 4.4%。
- **增长贡献 TOP5**：表（项目/增收贡献额/占收入增长比重）：核心产品销量增长 12,430 万元 45.2%；成长产品放量增长 7,320 26.6%；客户拓展增长 4,280 15.6%；价格提升贡献 2,180 7.9%；新产品贡献 920 3.3%；合计 27,130 98.6%。
- **管理建议**：①优化产品结构，提升高毛利产品占比，改善毛利率水平；②加强费用管控，重点关注销售费用与管理费用的效率；③深化成本管理，推进降本增效，提升利润空间；④持续聚焦核心客户，扩大市场份额，稳定收入增长。

**底部经营结论**：`收入同比增长12.6%，但净利润预算完成率92.1%；利润缺口主要来自毛利率和费用。`

> 设计观察：这一页的精髓是**瀑布图归因**（把"预算差"拆成收入/毛利率/费用/其他四个因子）+ **增长贡献分解**（把增量拆到销量/放量/客户/价格/新品）。这是"财务专业度"的集中体现——不是展示数字，而是解释数字。

### 页面 3｜盈利能力分析（images/01_3.png）

**6 张 KPI 卡**：毛利率 30.3%（同比+0.9pp）｜营业利润率 13.3%（+0.5pp）｜净利率 7.6%（+0.3pp）｜年化 ROA 5.4%（+0.2pp）｜年化 ROE 12.6%（+0.6pp）｜EBITDA 率 15.1%（+0.4pp）。

**图表区**：
- **盈利能力趋势**（1-7月）：三线图。毛利率 26.8→27.2→28.1→28.7→29.3→29.8→30.3；营业利润率 11.5→11.8→12.2→12.6→12.9→13.1→13.3；净利率 6.3→6.5→6.8→7.0→7.2→7.4→7.6。
- **杜邦分析**：树状分解图。年化 ROE 12.6% = 净利率 7.6% × 总资产周转率 0.71 次 × 权益乘数 2.33；下层挂基础数：净利润 9,674 万元、营业收入 126,895 万元、总资产 368,025 万元、所有者权益 157,657 万元。
- **经营单元盈利排名**：柱状图（净利润率%）：制造A 10.9、服务D 8.7、制造B 8.2、贸易C 4.5、海外E 3.8。
- **盈利质量**：表（指标/本期/同比变化/质量评价）：净利率 7.6% +0.3pp 提升；现金毛利率 9.2% +0.4pp 提升；税后经营净利率 7.1% +0.2pp 提升；资产周转率(ROA) 5.4% +0.2pp 提升；权益回报率(ROE) 12.6% +0.6pp 提升。
- **提升抓手**：表（抓手/重点措施/预期影响）：①提升净利率——优化产品结构，控制成本费用——+0.5pp；②提升周转率——加快存货周转，强化应收管理——+0.3pp；③优化资本结构——降低负债成本，合理利用杠杆——+0.2pp；④提高现金转化——强化管理费用，减少低效占用——+0.2pp。

**底部经营结论**：`年化ROE为12.6%，盈利改善主要来自净利率提升；海外E与贸易C仍是重点改善单元。`

> 设计观察：**杜邦分析做成可视化树**是财务驾驶舱的专业标志性设计；"提升抓手"表直接把 ROE 拆解成 4 个可操作杠杆并量化预期影响（+x pp），这是"从分析到行动"的桥。

### 页面 4｜费用分析（images/01_4.png）

**8 张 KPI 卡**：销售费用 7,205 万元｜管理费用 5,786 万元｜研发费用 4,353 万元｜财务费用 1,258 万元｜期间费用 18,602 万元｜期间费用率 14.7%｜预算超支 932 万元（橙色警示）｜费用同比 +8.4%。

**图表区**：
- **期间费用趋势**（1-7月）：堆叠柱状图（销售/管理/研发/财务四色）+ 橙色预算线。
- **费用增长与收入增长矩阵**：散点四象限，X=收入增长率，Y=费用率。象限标注：合理投入（左上）/ 重点管控（右上）/ 高效改善（左下）/ 低效扩张（右下）。落点：管理费用（约 -5%，12%）、销售费用（约 15%，13%）、财务费用（约 0%，-2%）、研发费用（约 8%，-5%）。
- **费用预算执行**：表（费用类别/预算执行率/状态）：销售费用 103.2% 超支（红）；管理费用 108.6% 超支（红）；研发费用 96.4% 节约（绿）；财务费用 101.8% 超支（红）。
- **超支原因**：表：销售费用——市场推广活动增加、广告宣传费用超预算；管理费用——咨询服务费、差旅及会议费超预算；研发费用——人员效率提升，研发外包费用低于预算；财务费用——汇兑损失增加、利息费用超预算。
- **降费措施**：表：销售费用——优化推广渠道，压降低效营销支出；管理费用——严控差旅及会议费用，减少咨询支出；研发费用——保持研发效率，持续优化资源配置；财务费用——加强汇率管理，优化融资结构。

**底部经营结论**：`期间费用率14.7%，预算超支932万元；管理费用是主要超支来源，需压降非刚性支出。`

> 设计观察：**费用×收入增速四象限**（合理投入/重点管控/高效改善/低效扩张）是非常值得借鉴的管理视角——费用高低本身无对错，要与收入增速组合判断。超支原因→降费措施两表构成"原因—措施"闭环。

## 四、可直接借鉴的产品设计清单

1. **页面骨架范式**：KPI 卡行 → 大图表 → 明细/清单表 → 底部"经营结论"一句话。每页都有判断句，这是"分析工具"与"报表工具"的分水岭。
2. **双基准对比**：每个指标同时给"同比"和"较预算"（或"较目标"）。
3. **归因三件套**：瀑布图（预算差异分解）、增长贡献 TOP5、杜邦分析树。
4. **专业指标库**：DSO/DIO/DPO/CCC、净现比、收现比、利息保障倍数、净负债/EBITDA、速动比率、现金短债比、收入抵销率、内部交易匹配率……全部内置、全部带控制线或预警线。
5. **风险→行动闭环**：预警清单（带等级）→ 管理层关注（带负责人与期限）→ 应对措施，跨页面呼应。
6. **中国报表直连**：4 张标准财务报表 + 字段映射 + 勾稽校验，即"指标定义系统"的数据底座。
7. **集团视角**：管理口径/合并口径双轨、抵销桥、单元矩阵与排名。
