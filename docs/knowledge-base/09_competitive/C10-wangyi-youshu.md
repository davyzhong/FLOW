# C10 · 网易有数 BI 竞品调研

> 调研日期：2026-09-11｜方式：公开网络资料调研（官网/用户手册/案例文章），非产品实测｜可信边界：二次摘要，功能以官方最新为准

## 1. 公司简介

网易有数 BI 是网易数帆（原网易云计算/大数据事业部，现与网易智企协同）旗下的敏捷 BI 产品，官方宣传语「让每个决策都有数据支撑」「像做 PPT 一样做报表」。依托网易技术品牌与「BI Master 大师计划」（个人版永久免费）获客，客户以行业头部为主：人保金服、名创优品、德邦快递、浙江日报报业、温氏股份、三花智控等，覆盖金融、制造、连锁零售、文旅等行业。2024 年以来重点转向 ChatBI/智能问数，旗下「网易知数」把「查数→问数→分析→归因→报告→决策建议」作为完整闭环叙事，财务分析是其公开主推的 AI 落地场景。

## 2. 产品定位与目标客群

- 定位：「自助式、智能化、集团型」的一站式数据分析可视化平台；强调像做 PPT 一样拖拽搭报告，降低业务人员门槛；
- 双客群策略：集团型企业（多租户、灵活权限、分域独立、风险预警）+ 成长型企业（快速部署、个人版免费、随业务扩张）；
- AI 转型：有数 BI V10 起内置「智能问数」（ChatBI），网易智企侧另有独立产品「网易知数」做企业经营分析的 AI 数据助手，两者共用指标口径体系；
- 客群行业：金融（银行）、制造、连锁、文旅、园区。

## 3. 模块与菜单布局

有数 BI 产品模块（官网 + 数帆产品页 + V10 用户手册）：

| 模块 | 核心子功能 |
|------|-----------|
| 数据源/数据连接 | 多种数据库接入、多源整合、本地 Excel |
| 数据集成与建模 | 可视化 ETL、拖拉拽建模，可结合网易 MPP 数据库一步构建轻量级数仓 |
| 报告（BI 报告） | PPT 式拖拽报告：图表组件 + 分析页 + 交互（详情见第 4 节） |
| 数据大屏 | 零代码搭建、支持 3D 数字孪生大屏（EasyScreen 能力线） |
| 复杂报表 | 类 Excel 交互的中国式复杂报表设计器（EasyReport 能力线） |
| 自助取数 | 无需 SQL，拖拽自动生成查询；多 tab 页查询、TopN 筛选、查询历史、结果保存分享 |
| 数据填报 | 零代码表单制作与数据填报、审批流 |
| 数据门户 | 低代码集成多份报告，搭企业数据门户，带报告权限管理 |
| 智能问数（ChatBI） | 自然语言提问 → 理解 → 生成查询 → 数据提取整理计算 → 图表呈现 |
| 移动端 | 网页端 + 手机端应用 |

## 4. 界面布局分析

- **PPT 式报告**：核心交互是「像做 PPT 一样做报表」——报告由多页面（页签）组成，每页自由拖放图表、文本、图片组件；与帆软「仪表板」路线相比更强调报告的页面叙事性（这一点与 FLOW 报告中心最接近）；
- **报表三型**：报表制作分明细表、统计表、交叉表三类，交叉表支持多维透视；
- **交互**：多维度透视分析、表计算、跨视图粒度计算（LOD 类）、上卷下钻；筛选控件挂报告级；
- **智能问数交互**：基于平台**已配置好的指标与数据集**提问，支持多轮对话；系统自动理解含义、生成查询、返回图表，回答口径受指标配置约束；
- **门户布局**：数据门户把多报告按菜单/目录组织，权限按目录-报告两级管控，是集团型客户的统一入口形态。

## 5. 图表格式与可视化能力

- 官网强调「丰富的可视化图表库」：常规柱/条/线/饼/面积/组合图，以及漏斗、雷达、桑基、词云、散点、仪表盘、地图（地理信息分析）等；大屏侧支持 3D 组件、数字孪生场景；
- 复杂报表（EasyReport）：类 Excel 设计器，支持多级表头、合并、斜线表头等中国式复杂报表样式，与 BI 报告、门户集成；
- 大屏应用场景官方列示：活动数据监控、业务监控、风险预警、会议展览、对外接待/PR；
- 官网首页把「ChatBI 解锁隐藏洞察力」「3D 大屏零代码搭建」作为两大首屏卖点，图表库本身不标榜类型数量，差异化在报告形态而非图型丰富度。

## 6. 分析方法支持

- **表计算与跨视图粒度计算**：支持跨不同视图粒度的指标再计算（类似 Tableau LOD），是做占比、排名类衍生指标的基础；
- **上卷下钻**：维度层级钻取；
- **高级分析**：官方手册列示聚类、对比、预测分析能力；
- **智能问数**：自然语言查询 + 计算生成，无需掌握 SQL；
- **网易知数的 AI 分析闭环**：查数→问数→分析→归因→报告→决策建议；支持**归因分析**环节；
- **一键生成报告**（远光智能问数相关介绍，同属网易体系对外叙事）：针对经营分析、财务分析报告需求，支持「模板化生成」与「提纲自定义」两种模式——按预设模板快速产出或按自定义提纲组织内容。

## 7. 财务与经营分析指标能力

- 网易智企官网明确列示「开箱即用的智能财务分析能力」：**财务分析报告（自动生成）、企业健康度检测、利润分析模型、异常财务数据识别**，以及企业经营管理分析、销售预测场景；
- **双模式问答保证口径一致**：智能问答区分「基于统一指标口径的精确问答」（面向财务、经营分析等对数据一致性敏感的场景）与「面向原始数据表的自由探索」模式——这是把指标库作为 AI 问数护栏的明确设计；
- 案例：
  - 三花智控「智能问数」数据智能体：构建「数据即洞察、问答即分析」的智能用数体系；
  - 三棵树：AI 智能分析助手为数千名销售人员生成**个性化经营分析报告**（财务数智化案例）；
- 有数 BI 集团型客户（温氏、名创优品等）以经营看板 + 移动端汇报为主，公开的财务模板库不如帆软丰富。

## 8. 对 FLOW 的可借鉴点

**界面布局**
1. **PPT 式多页报告**与 FLOW 报告中心的定位最接近，值得对照确认两点：有数的报告支持页签组织 + 组件自由布局 + 报告级筛选控件贯穿所有页，FLOW 报告中心若尚无「报告级全局筛选（期间/分部）贯穿全部页面」的机制，应补上；
2. 借鉴**数据门户作为统一入口**：FLOW 已有 AppShell 左侧导航，可参考有数把「报告门户 + 权限目录」做成驾驶舱之外的第二入口形态（按业务域组织的报告目录）。

**图表格式**
3. 有数的差异化在 3D 数字孪生大屏，对 FLOW 财务场景参考价值有限；真正可借鉴的是其**「报告叙事性」组件**：文本块与图表块同层混排（分析结论文字直接嵌在报告页内），FLOW 报告中心的「结论块 + 图表块」编辑器应保持这种一等公民混排，而不是图表只能配 caption；
4. 交叉表 + 表计算（占比/排名/汇总百分比）是财务明细呈现的刚需格式，FLOW 表格组件需覆盖。

**分析方法**
5. **双模式问答（精确口径模式 vs 自由探索模式）**是本批次调研中最值得 FLOW 抄的设计：FLOW 四问分析工作台的 AI 问答也应区分「走指标库的精确回答」和「探索原始数据的假设性回答」，并在 UI 上明示当前模式，财务场景的口径可信度直接决定产品可信度；
6. **一键生成报告的两种模式**（模板化生成 / 提纲自定义）：FLOW 报告中心由 AI 生成经营分析报告时，可同时支持「按标准经营月报模板生成」和「用户给提纲生成」，前者保稳定、后者保灵活；
7. 网易知数的**六步闭环**（查数→问数→分析→归因→报告→决策建议）可作为 FLOW 用户旅程的对照清单：FLOW 已覆盖报告与四问分析，应检查「查数/问数」入口是否足够轻。

**指标公式**
8. 网易把「指标与数据集先配置、AI 后消费」作为问数前提——与 FLOW 指标库驱动架构同向，验证了「指标库是 AI 财务分析的护栏」这一判断；FLOW 指标库应保证每个指标有清晰的名称、同义词、口径描述与适用时间粒度，直接决定问数命中率；
9. 其「利润分析模型」「企业健康度检测」作为**开箱即用能力**而非模板的打包方式值得 FLOW 借鉴：把财务分析方法论产品化成模型（而非空模板），用户带入数据即出结论——这正是 FLOW 相对通用 BI 的差异化方向，网易已经验证市场接受度。
