# 归档说明与限制

## 归档范围

本次归档覆盖：

- 历史 ChatGPT 完整会话 Markdown；
- 当前 Codex 会话的机器级 JSONL 快照；
- 当前 Codex 会话的 user/assistant 可读转录；
- 五份研究资料的 Markdown、文本、原始 HTML 和全部本地图片（2026-09-04 增补第六篇《经营分析和财务分析的区别》：HTML 原件、9 张图解卡片与逐卡转录）；
- 综合研究结论；
- 六张物流供应链日报截图；
- 一张外部财务驾驶舱参考图；
- 本轮浏览器设计原型；
- 已批准 FLOW V1 设计规格快照；
- 项目状态、决策日志、链接、图片、来源和接续指南；
- 文件级清单和 SHA-256 哈希。

## 有意排除

- 研究目录中的 `.mimosa` 运行状态；
- 当前视觉伴随服务器的 PID、临时访问密钥和运行状态；
- Git 内部对象和钩子；
- 与项目内容无关的系统或插件安装文件。

这些内容不能帮助恢复项目知识，且部分只在当前机器和会话中有效。

## 会话快照边界

Codex JSONL 在活跃任务期间持续写入。本知识库保存的是归档操作接近完成时的快照，可能不包含本次任务最终回复之后的事件。知识内容本身已经写入知识库文档，不依赖最后一条会话消息。

## 外部链接风险

- ChatGPT 分享链接、微信公众号和 CDN 链接未来可能失效；
- 因此关键正文、HTML 和图片均优先以本地副本保存；
- `all_urls_extracted.txt` 是完整机械提取结果，含微信页面脚本和广告链接噪声；
- `LINK_CATALOG.md` 是人工整理的有效入口。

## 版权与使用

研究网页、截图和第三方图片按用户提供的研究背景做本地项目归档。后续公开发布或商业使用时，应重新核查来源授权、品牌和版权，不应直接复用第三方水印、品牌或完整内容。
