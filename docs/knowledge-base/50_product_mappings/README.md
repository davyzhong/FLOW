# 产品知识映射层（50_product_mappings）

知识进入产品的唯一转换入口。每项映射：业务知识（卡/手册 ID）→ FLOW 对象 → 当前能力 → L1–L4 → 采用状态 → 缺口 → 决策/规格引用。产品规格不得从来源文章直接产生。
