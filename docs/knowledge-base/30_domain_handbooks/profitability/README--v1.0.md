# 盈利能力（领域手册 v1.0）

> 要点式 v1.0：结构完整、内容从既有知识卡与评估册提炼；深化在后续版本。

## 1. 领域定义与边界

含：利润层级（毛利/EBIT/净利）、盈利质量、多维盈利。不含：税务筹划。

## 2. 核心对象与术语

利润、利润中心、期间。

## 3. 关键指标与口径锚点

毛利率、净利率、净现比、单票利润（口径细则见关联知识卡与指标库 v1.1）。

## 4. 分析维度

利润中心 × 产品 × 客户 × 期间。

## 5. 比较、分解与下钻逻辑

层级口径显式；多维盈利须授权（U9/O5）。

## 6. 数据要求（L1–L4）

L1 + L2/L3 授权后。

## 7. 典型分析路径

利润→层级拆→质量检验（现金）→多维下钻。

## 8. 风险与误用

忽视非经常项；未授权内部多维；权限与敏感见 GOV-AUTH-001。

## 9. 知识卡与产品映射

关联知识卡：FIN-QUAL-001, FIN-MARGIN-001, OPS-PROFIT-001；产品采用状态见 `50_product_mappings/FLOW-PRODUCT-MAPPING--v1.0.md`。
