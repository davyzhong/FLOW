# 财务报表基础（领域手册 v1.0）

> 要点式 v1.0：结构完整、内容从既有知识卡与评估册提炼；深化在后续版本。

## 1. 领域定义与边界

含：三表结构、科目分类、勾稽关系、报表阅读与附注重建。不含：非报表编制/合并技术细节。

## 2. 核心对象与术语

报表、科目、报告主体、报告期间、勾稽断言。

## 3. 关键指标与口径锚点

勾稽通过率、缺表率、科目覆盖度（口径细则见关联知识卡与指标库 v1.1）。

## 4. 分析维度

报告主体 × 期间 × 准则。

## 5. 比较、分解与下钻逻辑

先勾稽校验再分析；口径变体显式声明；附注优先于估算。

## 6. 数据要求（L1–L4）

L1 公开披露（B01–B05 已实现抽取归一）。

## 7. 典型分析路径

披露文本→抽取→归一→勾稽→冻结→三表呈现。

## 8. 风险与误用

用勾稽通过证明科目正确；缺表硬造勾稽；权限与敏感见 GOV-AUTH-001。

## 9. 知识卡与产品映射

关联知识卡：FIN-STAT-001, FIN-EBITDA-001；产品采用状态见 `50_product_mappings/FLOW-PRODUCT-MAPPING--v1.0.md`。
