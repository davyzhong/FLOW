# 经营效率与经营分析（领域手册 v1.0）

> 要点式 v1.0：结构完整、内容从既有知识卡与评估册提炼；深化在后续版本。

## 1. 领域定义与边界

含：经营分析闭环（四问）、指标治理、组织维度效率。不含：精益生产工具集。

## 2. 核心对象与术语

经营指标、组织单元、异常、动作。

## 3. 关键指标与口径锚点

红黄绿灯指标、效率比率、异常闭环率（口径细则见关联知识卡与指标库 v1.1）。

## 4. 分析维度

组织 × 指标 × 期间。

## 5. 比较、分解与下钻逻辑

四问第一问只认冻结事实；异常须挂责任与期限。

## 6. 数据要求（L1–L4）

L1 + L2/L3。

## 7. 典型分析路径

事实→拆解归因→推演预警→行动跟踪。

## 8. 风险与误用

跳过事实直接归因；推演不标注；权限与敏感见 GOV-AUTH-001。

## 9. 知识卡与产品映射

关联知识卡：METHOD-QA-001, OPS-CFO-001, OPS-MASTER-001；产品采用状态见 `50_product_mappings/FLOW-PRODUCT-MAPPING--v1.0.md`。
