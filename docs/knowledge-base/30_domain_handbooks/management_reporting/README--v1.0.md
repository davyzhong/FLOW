# 管理报告与看板（领域手册 v1.0）

> 要点式 v1.0：结构完整、内容从既有知识卡与评估册提炼；深化在后续版本。

## 1. 领域定义与边界

含：月/季/年报结构、驾驶舱信息架构、报告生产闭环。不含：对外披露格式。

## 2. 核心对象与术语

报告、章节、指标卡、状态灯。

## 3. 关键指标与口径锚点

报告章节结构指标、状态灯分布（口径细则见关联知识卡与指标库 v1.1）。

## 4. 分析维度

报告类型 × 主体 × 期间。

## 5. 比较、分解与下钻逻辑

固定信息架构；状态灯阈值版本化；结论摘要先行。

## 6. 数据要求（L1–L4）

L1 + L2。

## 7. 典型分析路径

冻结事实→章节编排→状态灯→行动清单→发布冻结。

## 8. 风险与误用

模板数值当默认阈值；状态灯无版本；权限与敏感见 GOV-AUTH-001。

## 9. 知识卡与产品映射

关联知识卡：METHOD-REPORT-001, METHOD-QA-001；产品采用状态见 `50_product_mappings/FLOW-PRODUCT-MAPPING--v1.0.md`。
