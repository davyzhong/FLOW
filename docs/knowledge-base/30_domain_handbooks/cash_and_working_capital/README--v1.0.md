# 现金流与营运资本（领域手册 v1.0）

> 要点式 v1.0：结构完整、内容从既有知识卡与评估册提炼；深化在后续版本。

## 1. 领域定义与边界

含：三表现金流结构、FCF、营运资本周转、DSO/DPO/ITO。不含：资金交易与司库操作。

## 2. 核心对象与术语

经营/投资/融资现金流、应收、应付、存货。

## 3. 关键指标与口径锚点

净现比、FCF、DSO/DPO/ITO、现金转换周期（口径细则见关联知识卡与指标库 v1.1）。

## 4. 分析维度

主体 × 期间 × 客户（授权后）。

## 5. 比较、分解与下钻逻辑

FCF 口径声明（是否含资本化）；应收口径含票据与否声明。

## 6. 数据要求（L1–L4）

L1 公开 + L2 账龄（授权后）。

## 7. 典型分析路径

现金流结构→质量比率→营运资本周转→预警。

## 8. 风险与误用

FCF 口径混用；期末单点粉饰 DSO；权限与敏感见 GOV-AUTH-001。

## 9. 知识卡与产品映射

关联知识卡：FIN-RECV-001, FIN-QUAL-001；产品采用状态见 `50_product_mappings/FLOW-PRODUCT-MAPPING--v1.0.md`。
