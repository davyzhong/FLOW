# 财务 AI 治理（领域手册 v1.0）

> 要点式 v1.0：结构完整、内容从既有知识卡与评估册提炼；深化在后续版本。

## 1. 领域定义与边界

含：指标知识治理、AI 回答约束、授权与脱敏、知识工程。不含：通用 ML 工程。

## 2. 核心对象与术语

指标、知识卡、来源、授权状态。

## 3. 关键指标与口径锚点

治理态指标占比、来源可追溯率（口径细则见关联知识卡与指标库 v1.1）。

## 4. 分析维度

指标 × 知识 × 来源 × 发布。

## 5. 比较、分解与下钻逻辑

canonical 知识必有来源；推断必挂证据；授权类数值隔离。

## 6. 数据要求（L1–L4）

横切（L1-L4 全适用）。

## 7. 典型分析路径

来源登记→知识卡→复核→发布锁→产品映射→决策/规格。

## 8. 风险与误用

AI 摘要定稿；无源知识进规格；权限与敏感见 GOV-AUTH-001。

## 9. 知识卡与产品映射

关联知识卡：GOV-METRIC-001, GOV-AUTH-001, TECH-COPILOT-001；产品采用状态见 `50_product_mappings/FLOW-PRODUCT-MAPPING--v1.0.md`。
