# 财务分析（比率/杜邦/趋势/结构）（领域手册 v1.0）

> 要点式 v1.0：结构完整、内容从既有知识卡与评估册提炼；深化在后续版本。

## 1. 领域定义与边界

含：四大能力比率、杜邦分解、同型/趋势、现金流质量、报告叙事。不含：投资估值与市场择时。

## 2. 核心对象与术语

比率、分解树、趋势序列、结构占比。

## 3. 关键指标与口径锚点

净现比、毛利率-净利率差、ROE 三因子（口径细则见关联知识卡与指标库 v1.1）。

## 4. 分析维度

主体 × 期间 × 同业对标。

## 5. 比较、分解与下钻逻辑

负分母显式不可比；均值口径统一；同业对标先对准则。

## 6. 数据要求（L1–L4）

L1 公开 + L2 内部过程事实。

## 7. 典型分析路径

冻结事实→比率→分解→对标→叙事（客观三章节）。

## 8. 风险与误用

比率排序当价值判断；跨准则直比；权限与敏感见 GOV-AUTH-001。

关联知识卡：FIN-DUPONT-001, FIN-MARGIN-001, FIN-QUAL-001；产品采用状态见 `50_product_mappings/FLOW-PRODUCT-MAPPING--v1.0.md`。
