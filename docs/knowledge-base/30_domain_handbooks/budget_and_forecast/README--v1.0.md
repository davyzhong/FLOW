# 预算与预测（领域手册 v1.0）

> 要点式 v1.0：结构完整、内容从既有知识卡与评估册提炼；深化在后续版本。

## 1. 领域定义与边界

含：预算版本管理、预算-实际比较、滚动预测、差异拆解。不含：财务建模工具细节。

## 2. 核心对象与术语

预算版本、目标值、实际、差异。

## 3. 关键指标与口径锚点

预算达成率、差异额与差异率、量价贡献（口径细则见关联知识卡与指标库 v1.1）。

## 4. 分析维度

预算版本 × 科目 × 组织 × 期间。

## 5. 比较、分解与下钻逻辑

版本身份不可变；静态预算剥离规模效应再比较。

## 6. 数据要求（L1–L4）

L2（预算为内部数据，授权后）。

## 7. 典型分析路径

版本对齐→差异计算→瀑布拆解→归因→滚动修正。

## 8. 风险与误用

用摊月数据伪造预算基线；版本错配当差异；权限与敏感见 GOV-AUTH-001。

## 9. 知识卡与产品映射

关联知识卡：METHOD-REPORT-001；产品采用状态见 `50_product_mappings/FLOW-PRODUCT-MAPPING--v1.0.md`。
