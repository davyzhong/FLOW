# 收入与增长（领域手册 v1.0）

> 要点式 v1.0：结构完整、内容从既有知识卡与评估册提炼；深化在后续版本。

## 1. 领域定义与边界

含：收入结构、增长质量（价量拆分）、收入确认口径。不含：市场预测与获客策略。

## 2. 核心对象与术语

收入、量、价、确认口径、分部收入。

## 3. 关键指标与口径锚点

收入增长率的量价贡献、分部占比（口径细则见关联知识卡与指标库 v1.1）。

## 4. 分析维度

分部 × 客户群 × 产品线 × 期间。

## 5. 比较、分解与下钻逻辑

总额/净额法先对齐；分部口径与合并勾稽。

## 6. 数据要求（L1–L4）

L1 公开分部 + L2 内部明细。

## 7. 典型分析路径

收入→量价拆→分部拆→质量评估（增长是否带现金）。

## 8. 风险与误用

把收入增长当质量；忽视确认口径变更；权限与敏感见 GOV-AUTH-001。

## 9. 知识卡与产品映射

关联知识卡：FIN-MARGIN-001；产品采用状态见 `50_product_mappings/FLOW-PRODUCT-MAPPING--v1.0.md`。
