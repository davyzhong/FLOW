# 成本与费用（领域手册 v1.0）

> 要点式 v1.0：结构完整、内容从既有知识卡与评估册提炼；深化在后续版本。

## 1. 领域定义与边界

含：成本结构（环节/科目）、费用率、成本分摊方法。不含：制造成本法教材细节。

## 2. 核心对象与术语

成本科目、费用科目、分摊动因、环节。

## 3. 关键指标与口径锚点

单票成本、费用率、环节成本占比（口径细则见关联知识卡与指标库 v1.1）。

## 4. 分析维度

环节 × 科目 × 组织 × 期间。

## 5. 比较、分解与下钻逻辑

分摊规则白盒；科目变更口径显式；对标锚点注明企业期间。

## 6. 数据要求（L1–L4）

L2/L3（公开仅粗粒度）。

## 7. 典型分析路径

总成本→环节拆→动因拆→单票化→降本项。

## 8. 风险与误用

黑箱分摊；跨期直接环比；权限与敏感见 GOV-AUTH-001。

## 9. 知识卡与产品映射

关联知识卡：OPS-LOGI-001, OPS-CPP-001；产品采用状态见 `50_product_mappings/FLOW-PRODUCT-MAPPING--v1.0.md`。
