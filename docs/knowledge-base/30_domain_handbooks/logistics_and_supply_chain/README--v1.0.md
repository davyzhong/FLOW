# 物流与供应链分部经营（领域手册 v1.0）

> 要点式 v1.0：结构完整、内容从既有知识卡与评估册提炼；深化在后续版本。

## 1. 领域定义与边界

含：分部收入成本、单票经济模型、分部对标。不含：跨境合规/关务细节。

## 2. 核心对象与术语

分部、单票、环节成本、对标锚点。

## 3. 关键指标与口径锚点

单票收入/成本/利润、千元收入结算成本、CPP（口径细则见关联知识卡与指标库 v1.1）。

## 4. 分析维度

分部 × 线路 × 环节 × 期间。

## 5. 比较、分解与下钻逻辑

内部数值待 U9/O5 授权；对标锚点注明来源企业与期间。

## 6. 数据要求（L1–L4）

L1 分部披露 + L2/L3 授权后。

## 7. 典型分析路径

分部收入→单票化→环节成本→对标→改善项。

## 8. 风险与误用

公开数据摊月造假；对标值当标准；权限与敏感见 GOV-AUTH-001。

## 9. 知识卡与产品映射

关联知识卡：OPS-PROFIT-001, OPS-CPP-001, OPS-LOGI-001, OPS-MASTER-001；产品采用状态见 `50_product_mappings/FLOW-PRODUCT-MAPPING--v1.0.md`。
