---

## 一、利润表主要项目，一句话理解

| 分类 | 项目 | 大白话理解 |
|---|---|---|
| **主营业务赚钱** | 营业收入 | 卖包子的钱 |
|   | 营业成本 | 做包子的成本 |
|   | 营业税金及附加 | 为卖包子交的税 |
| **其他经营相关** | 期间费用 | 开包子铺花的其他钱（工资、租金等） |
|   | 投资收益 | 拿钱去理财赚的钱 |
|   | 资产减值损失 | 包子坏掉赔的钱 |
|   | 公允价值变动损益 | 股票/基金涨跌赚的钱（暂时不卖的浮动收益） |
| **意外之财/支出** | 营业外收入 | 政府补贴、小奖励 |
|   | 营业外支出 | 意外赔的钱 |
| **最终结果** | 利润总额 | 总共赚了多少钱（未扣税） |
|   | 所得税费用 | 交给国家的税 |
|   | 净利润 | 最终到手的钱 |

## 总结一句话：

利润表 = 赚钱的钱 - 花出去的钱 + 额外赚/赔的钱 - 税 = 到手的钱
