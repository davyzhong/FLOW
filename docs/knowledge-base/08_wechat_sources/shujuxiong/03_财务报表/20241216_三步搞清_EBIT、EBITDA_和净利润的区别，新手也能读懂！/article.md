案例
：

某公司财务数据如下（单位：万元）：

- 营业收入：10000
- 营业成本：7000
- 销售费用：500
- 管理费用：300
- 财务费用（利息）：200
- 折旧与摊销：100
- 所得税：300

计算：

1. EBIT =
    10000 - 7000 - 500 - 300 = 2200 万元
2. EBITDA =
    2200 + 100 = 2300 万元
3. 净利润 =
     EBIT - 财务费用 - 所得税 = 2200 - 200 - 300 = 1700 万元
