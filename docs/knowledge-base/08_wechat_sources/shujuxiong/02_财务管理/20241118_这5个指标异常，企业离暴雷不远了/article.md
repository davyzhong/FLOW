# 这5个指标异常，企业离暴雷不远了

> 来源：微信公众号「数据熊」 · 作者 Data Bear · 发布于 2024-11-18 06:45
> 原文链接：http://mp.weixin.qq.com/s?__biz=Mzg2MTg5OTgzNA==&mid=2247485327&idx=1&sn=6f66ebb371a644a5d41f338d0994a314&chksm=ce115adaf966d3cc22424ed43d78133e4bc672b1d07f8aa7d899218123ac333a9bce741dd24c

![图片](images/img001.gif)

企业的成功和失败往往都可以从一系列财务指标中找到蛛丝马迹。

如果你是一位企业管理者，或者对财务管理有兴趣，这五个关键指标能够帮你判断企业是否正走在危险的边缘。

这些指标一旦出现异常，可能意味着企业距离暴雷已经不远了。

今天我们就来一起看懂这些危险信号。

最后一个最关键

。

![图片](images/img002.jpg)

1. 存贷双高

存贷双高意味着企业账上既有大量存款，同时也有大量贷款。

计算方式：

 主要通过观察企业的资产负债表中存款和贷款的数额是否同时处于高位来判断

这种情况往往说明企业的资金效率非常低，拿着一堆贷款却又不去有效利用，资金一方面闲置，另一方面却在不断支付利息。这就像家里有很多现金却又在高利率下借钱过日子，听起来就不太对劲。长期来看，这样的企业往往内控有问题，容易出现资金链断裂的风险。

![图片](images/img003.jpg)

2. 速动比率小于1

速动比率是衡量企业流动资产（扣除存货）与流动负债之间的比例。

计算方式：

 速动比率 = （流动资产 - 存货） / 流动负债

简单来说，就是企业如果突然需要还债，手里有多少"随时可以变现"的资产去应对。一般情况下，速动比率低于1就需要警惕，尤其是在行业环境变差或者市场竞争激烈的情况下，这种"救急钱"不足的企业，往往难以撑过风暴。

![图片](images/img004.jpg)

3. 现金短债比小于1

现金短债比就是企业的现金及等价物和一年内到期的短期债务之间的比例。

计算方式：

 现金短债比 = 现金及现金等价物 / 短期债务

它反映了企业是否有足够的现金来应对短期的债务压力。通俗点说，这个指标就像企业的"救命稻草"，现金是随时可以花的，而短期债务是随时要还的。如果这个比率过低，意味着企业一旦面临到期债务，可能就没有足够的现金去应付。现金短债比低于1，企业就要开始警惕了，这可能是"暴雷"的前奏。

![图片](images/img005.jpg)

4. 利息保障倍数小于1

利息保障倍数反映企业的利润对利息费用的覆盖能力，简单说，就是企业赚的钱够不够支付借债的利息。

计算方式：

利息保障倍数 = 息税前利润（EBIT） / 利息支出

如果这个倍数低于1.5，说明企业可能已经挣不到足够的钱去还利息了。我们可以把这个比率想象成企业的防护罩，一旦罩子变得太薄，利息压顶，企业的财务压力就会急剧增大。

![图片](images/img006.jpg)

5. 经营现金流利息保障倍数小于1

经营现金流利息保障倍数
，用来衡量企业用经营活动赚来的现金是否足以覆盖借款的利息。

计算方式：

经营现金流利息保障倍数
 = 经营活动产生的现金流净额 / 利息支出

这个指标和利息保障倍数有点类似，但它看的是企业真实的现金流，而不是账面上的利润。这个比率一旦持续低于1，意味着企业的经营收入连利息都还不起，长期下去，企业只能靠借新还旧，风险极高。

![图片](images/img007.jpg)

以上五个指标可以说是企业的
"健康体检表"
，它们直接反映了企业的偿债能力、经营效率和现金状况。如果这些指标出现问题，那么企业暴雷的风险将大幅增加。企业管理者应该时刻关注这些指标，做到未雨绸缪，及时调整经营策略，以免陷入困境。

每一个企业的未来，都掌握在今天的决策之中。让我们学会透过数字看本质，掌控企业发展的方向。

"风雨之后，方能见彩虹，管理好财务风险，才能迎来企业的光明未来。"
