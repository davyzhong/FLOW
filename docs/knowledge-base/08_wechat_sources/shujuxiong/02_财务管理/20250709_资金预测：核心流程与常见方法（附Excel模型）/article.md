## 一、资金预测到底预测什么？

简单说，就是预测企业未来某一段时间内的现金流动，具体包括：

- 预计未来

   收到多少钱

   （现金流入）
- 预计未来

   要付多少钱

   （现金流出）
- 推算未来

   资金缺口

   或

   结余

预测维度可以分为：

| 类型 | 说明 |
|---|---|
| 预测周期 | 通常分为**短期（1-3个月）**、**中期（3-12个月）**、**长期（1年以上）** |
| 颗粒度 | 可按**月、周、日**进行预测 |
| 预测对象 | 可对**整体资金**、**单业务板块**、**项目**、**子公司**进行预测 |
| 场景驱动 | 可用于**资金统筹、融资安排、付款审批、投资计划制定**等 |

## 二、资金预测的五步流程

如果你不知道怎么下手，不妨参考下面这套“五步法”：

### 1. 明确预测目标与周期

是为了解决短期现金周转问题？还是要做年度资金统筹安排？不同目标，对应的周期和方法就不同。

### 2. 建立预测模型与数据口径

统一哪些是“应收预测来源”、哪些是“支出预计”，用哪个版本的预算，哪些付款按合同拆解，哪些可按历史趋势线外推。

标准统一，模型清晰，是预测准确的基础。

### 3. 数据汇总与清洗

数据通常来源于ERP、OA、预算系统、项目系统、业务填报表等，往往“不干净”，需

清洗、去重、补全、合理调整

，否则预测会很离谱。

### 4. 模拟预测与滚动更新

通过模型跑出未来的收支与余额情况，

每月更新、每周校准、临时补测

。动态跟踪，才有意义。

### 5. 分析偏差与改进

预测≠一锤定音，偏差分析要定期做，复盘哪些环节估错了、口径不一致了、业务判断不准了，然后持续优化。

---

## 三、资金预测常用的方法

资金预测没有万能公式，但可以结合以下几类方法灵活应用：

### 1. **预算驱动法**（适合中长期）

- 依据预算科目（如收入、采购、人力等）推导出相应的资金流入/流出；
- 常用于年度、季度预测；
- 优点是结构清晰，但依赖预算编制质量。

### 2. **业务填报法**（适合短期）

- 各部门/单位每周上报下周应收应付情况，财务集中汇总；
- 实操性强，但数据收集成本高；
- 特别适合工程、项目类企业。

### 3. **合同拆解法**

- 将合同按付款条款进行时间分解；
- 对于大额项目付款、长期合同类交易，预测效果更准；
- 但需维护合同台账。

### 4. **历史趋势法**

- 通过过去月份的收支趋势进行线性或非线性外推；
- 适合季节性明显或周期性稳定的企业；
- 但对突发事件无感知。

### 5. **AI+算法模型法**（进阶）

- 借助Python、Power BI、机器学习，训练预测模型；
- 对于销售收入预测、采购付款预测有一定优势；
- 要有数据基础与技术团队。

---

## 四、常见的资金预测报表模板

根据实践经验，企业资金预测表一般至少包含以下几个模块：

| 模块 | 说明 |
|---|---|
| 基础信息 | 项目名称、公司名称、预测日期等 |
| 现金流入 | 销售回款、租金、投资收益等 |
| 现金流出 | 采购付款、人工成本、税金、投资支出等 |
| 资金余额 | 每日/每周/每月的期初、期末余额 |
| 偏差分析 | 实际与预测的对比、偏差原因说明 |

> 可结合Power BI进行可视化呈现，比如现金流入趋势图、资金缺口雷达图、月度滚动预测表等，便于高层快速掌握整体趋势。

---

## 五、如何提升预测准确性？

1. 建立数据联动机制

    ：让业务系统与资金预测模板联动，减少人工干预。
2. 推动业务参与预测

    ：不是财务“拍脑袋”，而是业务部门要同步给出真实的预计付款计划。
3. 偏差复盘常态化

    ：建立“预测-执行-偏差-纠偏”的闭环。
4. 根据预测做决策

    ：预测不是为了“完成任务”，而是要影响付款节奏、融资安排、投资决策。
