> 摘要：国家层面的 “十五五” 规划（2026-2030） 前期调研正如火如荼。作为主力部门，财务部应该早做打算。

> 国家层面的
>
> “十五五” 规划（2026-2030）
>
>  前期调研正如火如荼。对国有企业来说，提前一年锁定战略方向、分解资源保障，是赢在下一个五年的关键一招。本文结合最新政策信号和央企、地方国企的实践经验，为大家梳理一套
>
> “可直接落地的十五五规划编制框架”
>
> ，希望成为您启动内部规划项目的“第一份作业指导书”。

---

## 一、“五句箴言”抓住编制总纲

| 关键词 | 要义 |
|---|---|
| **对标战略** | 与国家—地方—行业三层政策同频共振，锁定 *“新质生产力、双碳、数字化、开放型经济”* 等总基调 |
| **价值导向** | 以“价值创造—价值提升—价值兑现”为主线，指标设置围绕 EVA、ROIC、自由现金流 |
| **协同创新** | 研发、资本、数字三类资源“一张图”协同；搭建跨子公司共享平台 |
| **风险可控** | 在每一战略举措后配置“风险清单+对策包”，形成 *正向目标* 与 *负向底线* 双保险 |
| **数字赋能** | 用 **Power BI / 数据中台** 做监测闭环：日常经营看板 + 季度策略信号灯 |

---

## 二、规划编制“10 步法”一览

| 步骤 | 主要任务 | 关键产出 |
|---|---|---|
| **1** | **项目启动**明确牵头部门、组建跨层级 PMO | 组织架构图、项目章程、时间表 |
| **2** | **外部环境扫描**PEST、五力、行业赛道分析 | 环境研究报告、机会/威胁清单 |
| **3** | **内部能力诊断**SWOT、VRIO、财务健康度评估 | 能力评估矩阵、优势/短板清单 |
| **4** | **战略定位与愿景**对齐国家政策与企业使命 | 愿景声明、战略定位陈述 |
| **5** | **发展目标设定**财务、运营、ESG 指标 OKR 化 | 目标分解表、指标基线值 |
| **6** | **战略举措与重点工程“5+X” 行动方案** | 举措路线图、里程碑计划 |
| **7** | **资源保障与投资规划CAPEX 滚动测算、资金来源设计** | 投资计划表、融资方案 |
| **8** | **风险识别与应对构建风险矩阵与缓解对策** | Top 10 风险清单、Mitigation Playbook |
| **9** | **审议与发布三级评审（部门→高管→董事会）** | 评审纪要、正式发布文件 |
| **10** | **监控与动态调整预算-绩效-战略三维联动监控** | Power BI 仪表盘、滚动修订机制 |

---

## 三、六大关键模块拆解

| 模块 | 关注要点 | 典型指标 |
|---|---|---|
| **双碳与可持续** | *“双碳路线图”*、绿色供应链、节能改造 | tCO₂e/收入、绿色电力占比 |
| **数字化与智能化** | AI、工业互联网、数据中台建设 | 数字化收入占比、数据资产 ROI |
| **全球化布局** | RCEP、新“一带一路”项目、国际并购 | 境外收入占比、合规合规指数 |
| **资本运营** | 产业基金、专业化整合、资产证券化 | 股东回报率、资本成本 |
| **人才与组织** | 关键人才留存、混合所有制“跟投”机制 | 关键岗位流失率、人效（收入/人） |
| **社会责任与党建** | 乡村振兴、共同富裕、廉洁合规 | CSR 评级、合规事件数 |

---

## 四、工具箱：让规划更“能算会看”

| 工具 | 用法示范 |
|---|---|
| **战略地图×平衡计分卡** | 把愿景→目标→指标→行动连成逻辑链 |
| **情景规划（Scenario Planning）** | “基准 / 按下行 / 创新突破”三情景，对比 CAPEX、ROIC |
| **Power BI 战略仪表盘** | 15 分钟刷新一次实时指标，战略执行一眼掌握 |
| **DCF+Real Options** | 大额投资项目做二次评估，给决策层留“后悔药” |
