# 财务各岗位主要工作流程（附详细清单）

> 来源：微信公众号「数据熊」 · 作者 Data Bear · 发布于 2025-06-17 07:00
> 原文链接：http://mp.weixin.qq.com/s?__biz=Mzg2MTg5OTgzNA==&mid=2247488374&idx=1&sn=cc8a8571fe52806825fee3e24027380c&chksm=ce114e23f966c735d967efe500cd6e19734f185098b02718b1a39674ba10f142e22b8bb71db3
> 摘要：在大多数人眼里，财务部就等于“算账的”。

在大多数人眼里，财务部就等于“算账的”。可真走进来看，你会发现这里简直是一座微型工厂：出纳像传送带，AP/AR像加油站，总账像质检车间，FP&A像控制室……今天就带大家逛一圈，看看财务各岗位的
核心工作流程
 是如何协同运转、让企业数字飞起来的。

---

## 1. 出纳（Treasury & Cashier）

| 流程环节 | 说明 |
|---|---|
| **工作起点** | 经营活动产生收付款申请，或 ERP 自动推送付款指令 |
| **关键节点** | 1. 审核支付申请 → 2. 银行付款或收款登记 → 3. 下载并核对回单 → 4. 更新资金日报 |
| **最终输出** | ① 回单影像与系统流水  ② 每日/每周/每月资金报告  ③ 准确的账户余额与现金盘点记录 |

---

## 2. 应收会计（AR）

| 流程环节 | 说明 |
|---|---|
| **工作起点** | 业务系统（OMS/ERP）完成出库并生成应收单据 |
| **关键节点** | 1. 开具增值税发票 → 2. 发票寄送与电子同步 → 3. 银行回单匹配 → 4. 客户对账&催收 |
| **最终输出** | ① 应收账龄分析表  ② 催收进度跟踪表  ③ 坏账准备计提分录 |

---

## 3. 应付会计（AP）

| 流程环节 | 说明 |
|---|---|
| **工作起点** | 采购模块下达 PO，仓储确认收货 |
| **关键节点** | 1. 三单匹配（PO/收货/发票） → 2. 编制付款申请 → 3. 出纳付款执行 → 4. 供应商月度对账 |
| **最终输出** | ① 付款台账与折扣收益明细  ② 与供应商已确认的对账单  ③ 准确计提的应付账款余额 |

---

## 4. 成本会计

| 流程环节 | 说明 |
|---|---|
| **工作起点** | 生产系统采集领料、工时、制造费用 |
| **关键节点** | 1. 费用归集到成本中心 → 2. 标准 vs 实际成本核算 → 3. 差异分析并与生产沟通 |
| **最终输出** | ① 单位成本报表  ② 差异分析报告  ③ 存货期末计价表 |

---

## 5. 总账会计（GL）

| 流程环节 | 说明 |
|---|---|
| **工作起点** | 各子模块（AR/AP/FA/成本）月末关账并生成汇总凭证 |
| **关键节点** | 1. 调整与重分类分录 → 2. 期末结账 → 3. 生成三大报表 → 4. 报表复核与审签 |
| **最终输出** | ① 资产负债表、利润表、现金流量表  ② 可向外报送的合规财报  ③ 月度财务包（含附注） |

---

## 6. 税务会计 / 税务专员

| 流程环节 | 说明 |
|---|---|
| **工作起点** | 当期已确认的销项/进项发票与总账数据 |
| **关键节点** | 1. 进项认证抵扣 → 2. 各税种申报表填列 → 3. 线上申报与缴税 → 4. 风险自查与稽查准备 |
| **最终输出** | ① 完整的纳税申报表  ② 税负率分析 & 筹划方案  ③ 稽查备查台账 |

---

## 7. 资金管理 / 融资

| 流程环节 | 说明 |
|---|---|
| **工作起点** | 各业务部门提交的资金计划 + 历史现金流趋势 |
| **关键节点** | 1. 周/月滚动预测 → 2. 资金池调拨 → 3. 融资方案比较与落地 → 4. 利息费用分摊 |
| **最终输出** | ① 资金预测表  ② 融资成本分析  ③ 银行授信使用报告 |

---

## 8. 财务分析（FP&A）

| 流程环节 | 说明 |
|---|---|
| **工作起点** | 上期实际经营数据 & 各部门预算目标 |
| **关键节点** | 1. 建模并编制预算 → 2. 月度滚动预测 → 3. 实际 vs 预算差异分析 → 4. 经营建议撰写 |
| **最终输出** | ① 经营分析报告 / Dashboard  ② 关键 KPI 预测  ③ 行动建议清单 |

---

## 9. 内控 & 内审

| 流程环节 | 说明 |
|---|---|
| **工作起点** | 已设计的流程与控制矩阵 |
| **关键节点** | 1. 抽样 Walkthrough → 2. 测试控制有效性 → 3. 出具缺陷整改计划 → 4. 复测与评级 |
| **最终输出** | ① 内控评价报告  ② 缺陷整改跟踪表  ③ 专项审计报告 |

---

## 10. 财务BP / 财务经理

| 流程环节 | 说明 |
|---|---|
| **工作起点** | 嵌入业务单元的年度/季度经营目标 |
| **关键节点** | 1. 用数据洞察机会 → 2. 与业务共创方案 → 3. 推动项目落地 → 4. 复盘并优化 |
| **最终输出** | ① 针对性业务改进方案  ② ROI 测算报告  ③ 业务与财务双语言对齐文件 |

---
