V1 包含

  • 模块化标准 Excel 数据包及外部 Excel 转换
  • 数据库标准中间层、指标语义和物流供应链模拟数据
  • Finance BP 高密度驾驶舱和结构化 Investigation
  • AI 解读、追问与报告编排
  • PPT、分析 Excel 和 HTML/PDF 月报

V1 暂不包含

  • 实时或日度经营监控

  • 问题派单、责任人、截止日期及整改闭环
  • 任意行业、任意复杂 Excel 的无限适配
