## 5. 图片使用约束

- 不修改原始图片；
- 衍生标注图或裁剪图应另存并注明来源；
- 研究图片中的示例数据不能被误认为 FLOW 的真实数据；
- 设计实现可以借鉴信息结构，但不得把第三方品牌、名称或水印直接作为 FLOW 产品内容。
